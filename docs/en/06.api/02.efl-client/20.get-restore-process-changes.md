---
title: getRestoreProcessChanges
description: Returns restore process changes for the given transaction.
---

`getRestoreProcessChanges()` returns raw change information for a restore process.
It wraps `ProcessApiClient::getRestoreProcessChanges()`.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function getRestoreProcessChanges(string $transactionId): string
```

## Parameters

| Name           | Type     | Required | Description                     |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Yes      | Identifier of the transaction. |

## Return value

- **Type**: `string` – raw response body describing restore-process changes.
