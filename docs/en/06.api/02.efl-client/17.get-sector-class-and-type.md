---
title: getSectorClassAndType
description: Returns sector, class and product type information for the given transaction.
---

`getSectorClassAndType()` retrieves sector, class and product type information in the context of a transaction.
It wraps `ProductsApiClient::getSectorClassAndType()` and maps the response to `SectorProductInfoTree`.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function getSectorClassAndType(
    string $transactionId,
    string $bearerToken
): SectorProductInfoTree
```

## Parameters

| Name           | Type     | Required | Description                     |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Yes      | Identifier of the transaction. |
| `bearerToken`  | `string` | Yes      | Bearer token.                  |

## Return value

- **Type**: [`SectorProductInfoTree`](../04.models/33.sector-product-info-tree.md) – sector, class and type information tree.
