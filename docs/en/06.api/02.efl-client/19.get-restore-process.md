title: getRestoreProcess
description: Returns restore process data (partner and token) for the given transaction.
---

`getRestoreProcess()` retrieves restore process data (partner and token) for a transaction.
It wraps `ProcessApiClient::getRestoreProcess()` and maps the response to `AuthenticateResponse`.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function getRestoreProcess(string $transactionId): AuthenticateResponse
```

## Parameters

| Name           | Type     | Required | Description                     |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Yes      | Identifier of the transaction. |

## Return value

- **Type**: [`AuthenticateResponse`](../04.models/26.authenticate-response.md) – restore process data (partner and token).
