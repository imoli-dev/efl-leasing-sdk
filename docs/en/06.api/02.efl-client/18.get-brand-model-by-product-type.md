---
title: getBrandModelByProductType
description: Returns brand and model information for the given product type in the context of a transaction.
---

`getBrandModelByProductType()` retrieves brand and model information for a selected product type and transaction.
It wraps `ProductsApiClient::getBrandModelByProductTypeIdAndPartnerGuid()` and maps the response to `BrandProductInfoTree`.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function getBrandModelByProductType(
    string $transactionId,
    int $productTypeId,
    string $bearerToken
): BrandProductInfoTree
```

## Parameters

| Name           | Type     | Required | Description                         |
| -------------- | -------- | -------- | ----------------------------------- |
| `transactionId`| `string` | Yes      | Identifier of the transaction.     |
| `productTypeId`| `int`    | Yes      | Product type identifier.           |
| `bearerToken`  | `string` | Yes      | Bearer token.                      |

## Return value

- **Type**: [`BrandProductInfoTree`](../04.models/34.brand-product-info-tree.md) – brand and model tree for the given product type.
