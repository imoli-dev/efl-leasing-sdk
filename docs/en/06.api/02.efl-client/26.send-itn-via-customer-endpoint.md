---
title: sendItnViaCustomerEndpoint
description: Sends ITN payload via the Customer ITN endpoint.
---

`sendItnViaCustomerEndpoint()` sends an ITN payload using the `/Customer/ITN` endpoint instead of the testing endpoint.
It wraps `CustomerApiClient::postItn()` and is typically used in more realistic integration scenarios.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function sendItnViaCustomerEndpoint(string $transactionsPayload): void
```

## Parameters

| Name                | Type     | Required | Description                                      |
| ------------------- | -------- | -------- | ------------------------------------------------ |
| `transactionsPayload` | `string` | Yes    | Raw transactions payload, typically XML.        |

## Return value

- **Type**: `void` – failures are reported via exceptions.
