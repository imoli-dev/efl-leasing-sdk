---
title: getLastProcessStatus
description: Returns the last process status string for a given transaction.
---

`getLastProcessStatus()` provides a convenient way to read the most recent status of a leasing process.
It wraps `ProcessApiClient::getLastStatus()` and returns the status as a plain string.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function getLastProcessStatus(string $transactionId, string $bearerToken): string
```

## Parameters

| Name           | Type     | Required | Description                     |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Yes      | Identifier of the transaction. |
| `bearerToken`  | `string` | Yes      | Bearer token.                  |

## Return value

- **Type**: `string` – raw status string as returned by the API.
