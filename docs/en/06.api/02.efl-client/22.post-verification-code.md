title: postVerificationCode
description: Posts a verification code for the given transaction.
---

`postVerificationCode()` submits a verification code for a transaction.
It wraps `ProcessApiClient::postVerificationCode()`.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function postVerificationCode(
    PostVerificationCode $code,
    string $bearerToken
): void
```

## Parameters

| Name         | Type                                                         | Required | Description                            |
| ------------ | ------------------------------------------------------------ | -------- | -------------------------------------- |
| `code`       | [`PostVerificationCode`](../04.models/43.post-verification-code.md) | Yes      | Verification code payload.            |
| `bearerToken`| `string`                                                     | Yes      | Bearer token.                          |

## Return value

- **Type**: `void` – failures are reported via exceptions.
