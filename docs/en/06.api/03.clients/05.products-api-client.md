---
title: ProductsApiClient
description: Low-level client for /Products endpoints used to fetch sector, class, type, brand and model information.
---

`ProductsApiClient` provides raw access to `/Products` endpoints.
All methods return `HttpResponse` and require a Bearer token.

## Class definition

- **Namespace**: `Imoli\EflLeasingSdk\Api`
- **Constructor**: accepts `EflHttpClient $http`.

It is used by [`EflClient`](../02.efl-client/01.overview.md) to expose product-related operations in a typed way.

## Methods

### getSectorClassAndType

Low-level wrapper over **GET `/lon/api/v1/Products/GetSectorClassAndType`**.

```php
public function getSectorClassAndType(
    string $transactionId,
    string $bearerToken
): HttpResponse
```

**Auth**: Bearer token.

**Parameters**

| Name           | Type     | Required | Description                     |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Yes      | Identifier of the transaction. |
| `bearerToken`  | `string` | Yes      | Bearer token.                  |

**Return value**

- **Type**: `HttpResponse` – when used via `EflClient`, the body is mapped to [`SectorProductInfoTree`](../04.models/33.sector-product-info-tree.md).

### getBrandModelByProductTypeIdAndPartnerGuid

```php
public function getBrandModelByProductTypeIdAndPartnerGuid(
    string $transactionId,
    int $productTypeId,
    string $bearerToken
): HttpResponse
```

**Auth**: Bearer token.

**Parameters**

| Name           | Type     | Required | Description                                         |
| -------------- | -------- | -------- | --------------------------------------------------- |
| `transactionId`| `string` | Yes      | Identifier of the transaction.                     |
| `productTypeId`| `int`    | Yes      | Product type identifier (sent to the API as string).|
| `bearerToken`  | `string` | Yes      | Bearer token.                                      |

**Return value**

- **Type**: `HttpResponse` – when used via `EflClient`, the body is mapped to [`BrandProductInfoTree`](../04.models/34.brand-product-info-tree.md).
