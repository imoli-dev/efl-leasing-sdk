## Namespace and purpose

`Imoli\EflLeasingSdk\Model\Verification\StatusBlueMedia` is an enum that describes the current status of a BlueMedia verification process.
It complements [`ResultBlueMedia`](41.result-blue-media.md) in [`BlueMediaProcessStateResponse`](40.blue-media-process-state-response.md).

## Class definition

- **Namespace**: `Imoli\EflLeasingSdk\Model\Verification`
- **Type**: enum `StatusBlueMedia`

```php
enum StatusBlueMedia: string

    case Pending = 'PENDING';
}
```

## Values

| Value     | String value | Description                                              |
|-----------|--------------|----------------------------------------------------------|

| `Error`   | `'ERROR'`    | An error occurred.                                       |
| `Pending` | `'PENDING'`  | Verification is still in progress.                       |
