---
title: restoreSessionAfterSigning
description: Restores customer session after signing for the given transaction.
---

`restoreSessionAfterSigning()` restores a customer session after the signing step for a transaction.
It wraps `RestorationApiClient::restoreSessionAfterSigning()` and maps the response to `AuthenticationRestorationResult`.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function restoreSessionAfterSigning(
    string $transactionId
): AuthenticationRestorationResult
```

## Parameters

| Name           | Type     | Required | Description                     |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Yes      | Identifier of the transaction. |

## Return value

- **Type**: [`AuthenticationRestorationResult`](../04.models/35.authentication-restoration-result.md) – restoration result.
