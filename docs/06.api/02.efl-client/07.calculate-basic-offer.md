---
title: calculateBasicOffer
description: Calculates a basic leasing offer for the given basket.
---

`calculateBasicOffer()` sends a calculation request for a basket of assets and returns a typed `EsbCalculateBasicOfferRestReturn` model.
Internally it wraps `CalculationApiClient::calculateBasicOffer()` and decodes the JSON response.
When the API responds with HTTP 200 and an empty body, the SDK returns an [`EsbCalculateBasicOfferRestReturn`](../04.models/06.esb-calculate-basic-offer-rest-return.md) instance created via `emptyForTransaction()`, with the provided transaction id and an empty list of variants.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function calculateBasicOffer(
    AssetToCalculation $basket,
    string $bearerToken
): EsbCalculateBasicOfferRestReturn
```

## Parameters

| Name         | Type                                                   | Required | Description                                           |
| ------------ | ------------------------------------------------------ | -------- | ----------------------------------------------------- |
| `basket`     | [`AssetToCalculation`](../04.models/02.asset-to-calculation.md) | Yes      | Basket of assets for which to calculate an offer.     |
| `bearerToken`| `string`                                               | Yes      | Bearer token used for authenticated calculation call. |

## Return value

- **Type**: [`EsbCalculateBasicOfferRestReturn`](../04.models/06.esb-calculate-basic-offer-rest-return.md) – typed result with offer variants and financial details.
