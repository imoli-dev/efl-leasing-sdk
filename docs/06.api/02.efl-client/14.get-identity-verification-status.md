---
title: getIdentityVerificationStatus
description: Returns the current identity verification status for the given transaction.
---

`getIdentityVerificationStatus()` polls the identity verification status for a transaction.
It wraps `CustomerApiClient::getIdentityVerificationStatus()` and maps the response to `BlueMediaProcessStateResponse`.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function getIdentityVerificationStatus(
    string $transactionId,
    string $bearerToken
): BlueMediaProcessStateResponse
```

## Parameters

| Name           | Type     | Required | Description                     |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Yes      | Identifier of the transaction. |
| `bearerToken`  | `string` | Yes      | Bearer token.                  |

## Return value

- **Type**: [`BlueMediaProcessStateResponse`](../04.models/40.blue-media-process-state-response.md) – current verification status.
