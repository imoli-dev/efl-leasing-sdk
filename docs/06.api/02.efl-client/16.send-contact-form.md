---
title: sendContactForm
description: Sends lead or contact data related to the leasing process.
---

`sendContactForm()` submits contact/lead information to the EFL API.
It wraps `LeadApiClient::sendContactForm()`.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function sendContactForm(
    string $transactionId,
    ContactData $contactData,
    string $bearerToken
): void
```

## Parameters

| Name           | Type                                             | Required | Description                                             |
| -------------- | ------------------------------------------------ | -------- | ------------------------------------------------------- |
| `transactionId`| `string`                                         | Yes      | Identifier of the transaction associated with the lead. |
| `contactData`  | [`ContactData`](../04.models/23.contact-data.md) | Yes      | Lead/contact data payload.                              |
| `bearerToken`  | `string`                                         | Yes      | Bearer token.                                           |

## Return value

- **Type**: `void` – failures are reported via exceptions.
