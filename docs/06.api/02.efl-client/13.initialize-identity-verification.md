---
title: initializeIdentityVerification
description: Initialises identity verification via BlueMedia and returns the initialisation result.
---

`initializeIdentityVerification()` starts an identity verification process for a transaction using BlueMedia.
It wraps `CustomerApiClient::initializeIdentityVerification()` and maps the JSON response to `VerificationInitializationResult`.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function initializeIdentityVerification(
    string $transactionId,
    VerificationInitializationParams $params,
    string $bearerToken
): VerificationInitializationResult
```

## Parameters

| Name           | Type                                                                         | Required | Description                                           |
| -------------- | ---------------------------------------------------------------------------- | -------- | ----------------------------------------------------- |
| `transactionId`| `string`                                                                     | Yes      | Identifier of the transaction.                       |
| `params`       | [`VerificationInitializationParams`](../04.models/37.verification-initialization-params.md) | Yes      | Parameters describing the verification setup.        |
| `bearerToken`  | `string`                                                                     | Yes      | Bearer token.                                        |

## Return value

- **Type**: [`VerificationInitializationResult`](../04.models/38.verification-initialization-result.md) – initialisation result with redirect URL and identifiers.
