title: getIdentityReturnUrlForDemo
description: Returns the identity verification return URL used in demo scenarios.
---

`getIdentityReturnUrlForDemo()` retrieves the identity verification return URL from the demo API.
It wraps `DemoApiClient::getIdentityReturnUrl()` and returns the raw URL string.

All methods on [`EflClient`](01.overview.md) may throw:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – when the EFL API returns an error response.
- [`HttpException`](../06.errors.md#httpexception) – when the HTTP transport fails.

## Method signature

```php
public function getIdentityReturnUrlForDemo(): string
```

## Parameters

This method does not accept any parameters.

## Return value

- **Type**: `string` – identity verification return URL for demo scenarios.
