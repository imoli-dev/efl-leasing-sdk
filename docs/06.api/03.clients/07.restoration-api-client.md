---
title: RestorationApiClient
description: Low-level client for /Restoration endpoints used to restore customer sessions.
---

`RestorationApiClient` provides raw access to `/Restoration` endpoints.
Methods return `HttpResponse` and do not use Bearer token authentication.

## Class definition

- **Namespace**: `Imoli\EflLeasingSdk\Api`
- **Constructor**: accepts `EflHttpClient $http`.

This client is used by [`EflClient`](../02.efl-client/01.overview.md) to implement session restoration flows.

## Methods

### restoreCustomerSession

Low-level wrapper over **GET `/lon/api/v1/Restoration/RestoreCustomerSession`**.

```php
public function restoreCustomerSession(string $payByLinkOrderId): HttpResponse
```

**Auth**: none.

**Parameters**

| Name             | Type     | Required | Description                                  |
| ---------------- | -------- | -------- | -------------------------------------------- |
| `payByLinkOrderId` | `string` | Yes    | Identifier used in pay-by-link flows.       |

**Return value**

- **Type**: `HttpResponse` – when used via `EflClient`, the body is mapped to `AuthenticationRestorationResult`.

public function restoreSessionAfterSigning(string $transactionId): HttpResponse
