## Namespace and purpose

`Imoli\EflLeasingSdk\Model\Calculation\FinancialInsurance` models the insurance component of an offer.
It is nested inside [`OfferFinancial`](09.offer-financial.md) and [`AssetOfferFinancial`](10.asset-offer-financial.md), separating insurance costs from pure financing.

## Usage in the SDK

- Used as `insurance` in [`OfferFinancial`](09.offer-financial.md) and [`AssetOfferFinancial`](10.asset-offer-financial.md).
- Allows applications to separate insurance costs from other financing components when displaying offers.
