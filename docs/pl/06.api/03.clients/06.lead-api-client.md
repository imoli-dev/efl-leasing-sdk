`LeadApiClient` zapewnia bezpośredni dostęp do punktów końcowych `/Lead`.
Metody zwracają `HttpResponse` i wymagają Bearer tokena.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Api`
- **Konstruktor**: przyjmuje `EflHttpClient $http`.

Jest używany przez [`EflClient`](../02.efl-client/01.overview.md) do udostępniania metod przesyłających dane leada/kontaktu.

## Metody

### sendContactForm

Niskopoziomowe opakowanie dla **POST `/lon/api/v1/Lead/SendContactForm`**.

```php
public function sendContactForm(
    string $transactionId,
    ContactData $contactData,
    string $bearerToken
): HttpResponse
```

**Autoryzacja**: Bearer token.

**Parametry**

| Nazwa          | Typ                                             | Wymagany | Opis                                                  |
| -------------- | ------------------------------------------------ | -------- | ----------------------------------------------------- |
| `transactionId`| `string`                                         | Tak      | Identyfikator transakcji powiązanej z leadem.         |
| `contactData`  | [`ContactData`](../04.models/23.contact-data.md) | Tak      | Ładunek danych leada/kontaktu.                        |
| `bearerToken`  | `string`                                         | Tak      | Bearer token.                                         |

Ciało żądania to ładunek JSON z `ContactData::toRequestPayload()`.

**Zwracana wartość**

- **Typ**: `HttpResponse` – surowa odpowiedź potwierdzająca przesłanie formularza kontaktowego / leada.
