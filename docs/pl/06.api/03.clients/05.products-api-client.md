`ProductsApiClient` zapewnia bezpośredni dostęp do punktów końcowych `/Products`.
Wszystkie metody zwracają `HttpResponse` i wymagają Bearer tokena.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Api`
- **Konstruktor**: przyjmuje `EflHttpClient $http`.

Jest używany przez [`EflClient`](../02.efl-client/01.overview.md) do udostępniania operacji związanych z produktami w sposób typowany.

## Metody

### getSectorClassAndType

Niskopoziomowe opakowanie dla **GET `/lon/api/v1/Products/GetSectorClassAndType`**.

```php
public function getSectorClassAndType(
    string $transactionId,
    string $bearerToken
): HttpResponse
```

**Autoryzacja**: Bearer token.

**Parametry**

| Nazwa          | Typ      | Wymagany | Opis                            |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |
| `bearerToken`  | `string` | Tak      | Bearer token.                   |

**Zwracana wartość**

- **Typ**: `HttpResponse` – gdy używane przez `EflClient`, ciało jest mapowane na [`SectorProductInfoTree`](../04.models/33.sector-product-info-tree.md).

### getBrandModelByProductTypeIdAndPartnerGuid

Niskopoziomowe opakowanie dla **GET `/lon/api/v1/Products/GetBrandModelByProductTypeIdAndPartnerGuid`**.

```php
public function getBrandModelByProductTypeIdAndPartnerGuid(
    string $transactionId,
    int $productTypeId,
    string $bearerToken
): HttpResponse
```

**Autoryzacja**: Bearer token.

**Parametry**

| Nazwa          | Typ      | Wymagany | Opis                                              |
| -------------- | -------- | -------- | ------------------------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.                         |
| `productTypeId`| `int`    | Tak      | Identyfikator typu produktu (wysyłany do API jako string). |
| `bearerToken`  | `string` | Tak      | Bearer token.                                     |

**Zwracana wartość**

- **Typ**: `HttpResponse` – gdy używane przez `EflClient`, ciało jest mapowane na [`BrandProductInfoTree`](../04.models/34.brand-product-info-tree.md).
