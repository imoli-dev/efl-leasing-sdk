`TestingApiClient` dostarcza narzędzia dostępne tylko w piaskownicy pod adresem `/Testing`.
Metody zwracają `HttpResponse` i wymagają Bearer tokena.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Api`
- **Konstruktor**: przyjmuje `EflHttpClient $http`.

Ten klient jest przydatny głównie do zautomatyzowanych testów w piaskownicy EFL.

## Metody

### sendItn

Niskopoziomowe opakowanie dla **POST `/lon/api/v1/Testing/SendITN`**.  
Wysyła spłaszczoną listę transakcji do punktu końcowego testowego piaskownicy EFL i zwraca surową odpowiedź HTTP opisującą sposób przetworzenia ładunku ITN.

```php
public function sendItn(array $transactionListFlattened, string $bearerToken): HttpResponse
```

**Parametry**

| Nazwa                      | Typ                   | Wymagany | Opis                                                       |
| ------------------------- | ---------------------- | -------- | ---------------------------------------------------------- |
| `transactionListFlattened`| `array<string, mixed>` | Tak      | Tablica asocjacyjna ze spłaszczonym ładunkiem listy transakcji. |
| `bearerToken`             | `string`               | Tak      | Bearer token dla punktu końcowego testowego piaskownicy.   |

Dane są wysyłane jako ciało JSON.

**Zwracana wartość**

- **Typ**: `HttpResponse` – surowa odpowiedź HTTP; ciało opisuje sposób przetworzenia ładunku ITN.
