`RestorationApiClient` zapewnia bezpośredni dostęp do punktów końcowych `/Restoration`.
Metody zwracają `HttpResponse` i nie używają uwierzytelniania Bearer tokenem.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Api`
- **Konstruktor**: przyjmuje `EflHttpClient $http`.

Ten klient jest używany przez [`EflClient`](../02.efl-client/01.overview.md) do implementacji przepływów przywracania sesji.

## Metody

### restoreCustomerSession

Niskopoziomowe opakowanie dla **GET `/lon/api/v1/Restoration/RestoreCustomerSession`**.

```php
public function restoreCustomerSession(string $payByLinkOrderId): HttpResponse
```

**Autoryzacja**: brak.

**Parametry**

| Nazwa             | Typ      | Wymagany | Opis                                        |
| ---------------- | -------- | -------- | ------------------------------------------- |
| `payByLinkOrderId` | `string` | Tak      | Identyfikator używany w przepływach pay-by-link. |

**Zwracana wartość**

- **Typ**: `HttpResponse` – gdy używane przez `EflClient`, ciało jest mapowane na `AuthenticationRestorationResult`.
