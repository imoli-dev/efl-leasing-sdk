`DemoApiClient` zapewnia dostęp do punktów końcowych `/Demo`.
Metody zwracają `HttpResponse` i nie używają uwierzytelniania Bearer tokenem.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Api`
- **Konstruktor**: przyjmuje `EflHttpClient $http`.

Ten klient jest używany głównie w środowiskach demonstracyjnych lub testowych, zazwyczaj poprzez wysokopoziomowe narzędzia pomocnicze.

## Metody

### getIdentityReturnUrl

Niskopoziomowe opakowanie dla **GET `/lon/api/v1/Demo/GetIdentityReturnUrl`**.

```php
public function getIdentityReturnUrl(): HttpResponse
```

**Autoryzacja**: brak.

**Parametry**

| Nazwa   | Typ | Wymagany | Opis                                      |
| ------ | ---- | -------- | ----------------------------------------- |
| _brak_ | –    | –        | Ta metoda nie przyjmuje żadnych argumentów. |

**Zwracana wartość**

- **Typ**: `HttpResponse` – ciało zawiera adres URL powrotu weryfikacji tożsamości jako ciąg znaków.
