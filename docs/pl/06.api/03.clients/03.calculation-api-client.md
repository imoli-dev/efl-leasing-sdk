`CalculationApiClient` zapewnia bezpośredni dostęp do punktów końcowych związanych z kalkulacjami pod adresem `/Calculation`.
Jest to klasa finalna, która zależy od `EflHttpClient`, wykonującego uwierzytelnione żądania HTTP.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Api`
- **Konstruktor**: przyjmuje pojedynczą zależność `EflHttpClient $http`.

W typowym kodzie wywołujesz te punkty końcowe pośrednio przez [`EflClient`](../02.efl-client/01.overview.md).

## Metody

### calculateBasicOffer

Niskopoziomowe opakowanie dla **POST `/lon/api/v1/Calculation/CalculateBasicOffer`**.

```php
public function calculateBasicOffer(
    AssetToCalculation $basket,
    string $bearerToken
): HttpResponse
```

**Autoryzacja**: Bearer token.

**Parametry**

| Nazwa         | Typ                                                    | Wymagany | Opis                                                                        |
| ------------- | ------------------------------------------------------ | -------- | --------------------------------------------------------------------------- |
| `basket`      | [`AssetToCalculation`](../04.models/02.asset-to-calculation.md) | Tak      | Koszyk przedmiotów do użycia w kalkulacji.                                  |
| `bearerToken` | `string`                                               | Tak      | Bearer token dla uwierzytelnionego żądania.                                 |

Ciało żądania jest budowane za pomocą `AssetToCalculation::toRequestPayload()`, a parametr zapytania `transactionId` jest pobierany z tego ładunku.

**Zwracana wartość**

- **Typ**: `HttpResponse` – gdy używane przez `EflClient`, ciało jest mapowane na [`EsbCalculateBasicOfferRestReturn`](../04.models/06.esb-calculate-basic-offer-rest-return.md).

### getBaseData

Niskopoziomowe opakowanie dla **GET `/lon/api/v1/Calculation/GetBaseData`**.

```php
public function getBaseData(string $transactionId, string $bearerToken): HttpResponse
```

**Autoryzacja**: Bearer token.

**Parametry**

| Nazwa          | Typ      | Wymagany | Opis                            |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |
| `bearerToken`  | `string` | Tak      | Bearer token.                   |

**Zwracana wartość**

- **Typ**: `HttpResponse` – ciało może być mapowane na [`CalculationData`](../04.models/05.calculation-data.md).

### acceptCalculation

Niskopoziomowe opakowanie dla **POST `/lon/api/v1/Calculation/AcceptCalculation`**.

```php
public function acceptCalculation(
    string $transactionId,
    int $calculationId,
    int $calculationVariantId,
    ?bool $basketCalculation,
    string $bearerToken
): HttpResponse
```

**Autoryzacja**: Bearer token.

**Parametry**

| Nazwa              | Typ                | Wymagany | Opis                                                              |
| ------------------ | ------------------ | -------- | ----------------------------------------------------------------- |
| `transactionId`    | `string`           | Tak      | Identyfikator transakcji.                                         |
| `calculationId`    | `int`              | Tak      | Identyfikator kalkulacji do zaakceptowania.                       |
| `calculationVariantId` | `int`         | Tak      | Identyfikator wariantu kalkulacji do zaakceptowania.              |
| `basketCalculation`| `bool\|null` | Nie      | Czy używana jest kalkulacja koszyka; wysyłane jako `"true"` / `"false"`. |
| `bearerToken`      | `string`           | Tak      | Bearer token.                                                     |

Ciało żądania to obiekt JSON z `calculationId` i `calculationVariantId`.

**Zwracana wartość**

- **Typ**: `HttpResponse` – odpowiedź bez silnie typowanego modelu; użyj statusu i ciała do diagnostyki.
