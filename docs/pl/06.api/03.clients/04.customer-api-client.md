---

`CustomerApiClient` zapewnia bezpośredni dostęp do punktów końcowych `/Customer`.
Metody zwracają `HttpResponse` i w większości wymagają Bearer tokena, z wyjątkiem ITN, który używa multipart form-data bez uwierzytelniania.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Api`
- **Konstruktor**: przyjmuje `EflHttpClient $http`.

Wysokopoziomowy [`EflClient`](../02.efl-client/01.overview.md) używa tego klienta wewnętrznie do operacji związanych z klientem.

## Metody

### postCustomerDataForLon

Niskopoziomowe opakowanie dla **POST `/lon/api/v1/Customer/PostCustomerDataForLon`**.

```php
public function postCustomerDataForLon(
    CustomerData $data,
    string $bearerToken
): HttpResponse
```

**Autoryzacja**: Bearer token.

**Parametry**

| Nazwa        | Typ                                             | Wymagany | Opis                                                                 |
| ------------ | ----------------------------------------------- | -------- | -------------------------------------------------------------------- |
| `data`       | [`CustomerData`](../04.models/15.customer-data.md) | Tak      | Pełny ładunek danych klienta, w tym identyfikator transakcji.       |
| `bearerToken`| `string`                                        | Tak      | Bearer token do uwierzytelnienia.                                   |

`transactionId` jest pobierany z `CustomerData::toRequestPayload()` i wysyłany jako parametr zapytania.  
Ciało żądania to pełny ładunek JSON z `CustomerData::toRequestPayload()`.

**Zwracana wartość**

- **Typ**: `HttpResponse` – odpowiedź bez dedykowanego modelu; sukces jest sygnalizowany statusem HTTP.

### postItn

Niskopoziomowe opakowanie dla **POST `/lon/api/v1/Customer/ITN`** przy użyciu multipart form-data.

```php
public function postItn(string $transactions): HttpResponse
```

**Autoryzacja**: brak (brak Bearer tokena).

**Parametry**

| Nazwa          | Typ      | Wymagany | Opis                                                              |
| -------------- | -------- | -------- | ----------------------------------------------------------------- |
| `transactions` | `string` | Tak      | Surowy ładunek transakcji, zazwyczaj XML, wysyłany jako pole formularza. |

Klient buduje żądanie multipart/form-data z pojedynczym polem o nazwie `transactions`.

**Zwracana wartość**

- **Typ**: `HttpResponse` – surowa odpowiedź potwierdzająca sposób przetworzenia ładunku ITN.
