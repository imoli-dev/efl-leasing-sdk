`ProcessApiClient` zapewnia bezpośredni dostęp do punktów końcowych `/Process` w API EFL Leasing Online.
Jest to klasa finalna, która zależy od `EflHttpClient`, odpowiedzialnego za budowanie adresów URL, uwierzytelnianie i wykonywanie żądań HTTP.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Api`
- **Implementuje**: brak (finalna klasa narzędziowa)
- **Konstruktor**:
  - Przyjmuje pojedynczą zależność: `EflHttpClient $http`.
  - Ta sama instancja `EflHttpClient` jest używana dla wszystkich żądań.

W większości aplikacji będziesz używać wysokopoziomowego [`EflClient`](../02.efl-client/01.overview.md), który wewnętrznie składa się z `ProcessApiClient`.

## Metody

### init

Niskopoziomowe opakowanie dla **GET `/lon/api/v1/Process/Init`**.

```php
public function init(
    string $bearerToken,
    ?string $positiveUrlResponse = null,
    ?string $negativeUrlResponse = null
): HttpResponse
```

**Autoryzacja**: Bearer token.

**Parametry**

| Nazwa                 | Typ                  | Wymagany | Opis                                                                        |
| --------------------- | -------------------- | -------- | --------------------------------------------------------------------------- |
| `bearerToken`         | `string`             | Tak      | Bearer token (zobacz [`EflClient::getAuthToken`](../02.efl-client/02.get-auth-token.md)). |
| `positiveUrlResponse` | `string\|null` | Nie      | Adres URL używany, gdy proces zakończy się sukcesem; wysyłany jako parametr zapytania `PositiveUrlResponse`. |
| `negativeUrlResponse` | `string\|null` | Nie      | Adres URL używany, gdy proces zakończy się niepowodzeniem lub zostanie anulowany; wysyłany jako `NegativeUrlResponse`. |

**Zwracana wartość**

- **Typ**: `HttpResponse` – surowa odpowiedź HTTP; ciało zazwyczaj zawiera adres URL przekierowania lub identyfikator procesu.
