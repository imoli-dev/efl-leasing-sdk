## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Customer\Person` modeluje osobę fizyczną powiązaną z firmą, w tym dane osobowe, adres, dokumenty i oświadczenia.
Jest osadzony wewnątrz [`Company`](16.company.md) jako część danych klienta.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Customer`
- **Klasa**: final `Person`

```php
final class Person
{
    public static function builder(): PersonBuilder;

    public function __construct(
        string $guid,
        string $firstName,
        string $lastName,
        string $nip,
        string $pesel,
        string $birthDate,
        string $birthPlace,
        bool $pep,
        Address $address,
        string $countryOfOriginId,
        array $identityDocuments,
        ?string $middleName = null,
        ?array $statements = null
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa                | Typ                         | Wymagane | Opis                                                     |
|----------------------|-----------------------------|----------|----------------------------------------------------------|
| `guid`               | `string`                    | Tak      | Identyfikator wpisu osoby.                               |
| `firstName`          | `string`                    | Tak      | Imię.                                                    |
| `lastName`           | `string`                    | Tak      | Nazwisko.                                                |
| `middleName`         | `string\|null`               | Nie      | Opcjonalne drugie imię.                                  |
| `nip`                | `string`                    | Tak      | Identyfikator podatkowy (NIP).                           |
| `pesel`              | `string`                    | Tak      | Powszechny Elektroniczny System Ewidencji Ludności (PESEL). |
| `birthDate`          | `string`                    | Tak      | Data urodzenia.                                          |
| `birthPlace`         | `string`                    | Tak      | Miejsce urodzenia.                                       |
| `pep`                | `bool`                      | Tak      | Czy osoba jest osobą zajmującą eksponowane stanowisko polityczne (PEP). |
| `address`            | `Address`                   | Tak      | Adres zamieszkania lub prowadzenia działalności.         |
| `countryOfOriginId`  | `string`                    | Tak      | Identyfikator kraju pochodzenia.                         |
| `identityDocuments`  | `IdentityDocument[]`        | Tak      | Lista dokumentów tożsamości.                             |
| `statements`         | `CustomerDataStatement[]\|null` | Nie    | Opcjonalne oświadczenia/zgody na poziomie osoby.         |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `PersonBuilder`       | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `Person`. |
| `toRequestPayload()` | instancji| `array<string,mixed>` | Serializuje dane osoby do struktury oczekiwanej przez EFL.           |

`toRequestPayload()` tworzy tablicę ze wszystkimi polami, w tym zagnieżdżonymi strukturami dla `address`, `countryOfOrigin` (jako obiekt Descriptor z `id`, `name`, `version`; SDK mapuje `countryOfOriginId` na pełny Descriptor), `identityDocuments` (każdy skonwertowany przez `toRequestPayload()`) oraz opcjonalnymi oświadczeniami (`statements`).

## Użycie w SDK

- Zawarty w tablicy `persons` w [`Company`](16.company.md).
- Używany pośrednio podczas budowania [`CustomerData`](15.customer-data.md) dla [`EflClient::submitCustomerData`](../02.efl-client/10.submit-customer-data.md).
