## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\OfferItem` reprezentuje pojedyncze aktywo lub grupę aktywów w koszyku leasingowym.
Jest częścią ładunku `AssetToCalculation` i przechowuje informacje o ilości, cenach i klasyfikacji, wraz z metadanymi `ItemDetail`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `OfferItem`

```php
final class OfferItem
{
    public static function builder(): OfferItemBuilder;

    public function __construct(
        int $count,
        string $id,
        float $vatRate,
        array $itemDetails,
        ?string $supplierId = null,
        ?string $type = null,
        ?string $category = null,
        ?float $totalAmountNet = null,
        ?float $netValue = null,
        ?float $grossValue = null
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa           | Typ           | Wymagane | Opis                                                     |
|-----------------|---------------|----------|----------------------------------------------------------|
| `count`         | `int`         | Tak      | Ilość elementu.                                          |
| `id`            | `string`      | Tak      | Identyfikator elementu w Twoim systemie.                 |
| `vatRate`       | `float`       | Tak      | Stawka VAT mająca zastosowanie do tego elementu.         |
| `itemDetails`   | `ItemDetail[]`| Tak      | Dodatkowe wpisy metadanych.                              |
| `supplierId`    | `string\|null` | Nie      | Opcjonalny identyfikator dostawcy.                       |
| `type`          | `string\|null` | Nie      | Opcjonalna klasyfikacja typu.                            |
| `category`      | `string\|null` | Nie      | Opcjonalna klasyfikacja kategorii.                       |
| `totalAmountNet`| `float\|null`  | Nie      | Całkowita kwota netto dla elementu.                      |
| `netValue`      | `float\|null`  | Nie      | Wartość netto elementu.                                  |
| `grossValue`    | `float\|null`  | Nie      | Wartość brutto elementu.                                 |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `OfferItemBuilder`    | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `OfferItem`. |
| `toRequestPayload()` | instancji| `array<string,mixed>` | Serializuje element oferty do struktury oczekiwanej przez EFL.       |

`toRequestPayload()` zwraca tablicę asocjacyjną zawierającą `count`, `id`, `vatRate`, `itemDetails` (każdy `ItemDetail` skonwertowany przez `toRequestPayload()`) oraz opcjonalnie `supplierId`, `type`, `category`, `totalAmountNet`, `netValue`, `grossValue`, gdy nie są one równe null.

## Użycie w SDK

- Używane wewnątrz [`AssetToCalculation`](02.asset-to-calculation.md) podczas budowania żądań obliczeń.
- Ostatecznie wysyłane przez `CalculationApiClient::calculateBasicOffer()` i konsumowane przez [`EflClient::calculateBasicOffer`](../02.efl-client/07.calculate-basic-offer.md).
