## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Verification\PostVerificationCode` reprezentuje ciało (body) punktu końcowego `/Process/PostVerificationCode`.
Przenosi identyfikator transakcji oraz kod weryfikacyjny wprowadzony przez użytkownika.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Verification`
- **Klasa**: final `PostVerificationCode`

```php
final class PostVerificationCode
{
    public static function builder(): PostVerificationCodeBuilder;

    public function __construct(
        string $transactionId,
        string $verificationCode
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa              | Typ      | Wymagane | Opis                                                     |
|-------------------|----------|----------|----------------------------------------------------------|
| `transactionId`   | `string` | Tak      | Identyfikator transakcji, dla której przesyłany jest kod. |
| `verificationCode`| `string` | Tak      | Kod dostarczony przez użytkownika lub system zewnętrzny. |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `PostVerificationCodeBuilder` | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `PostVerificationCode`. |
| `toRequestPayload()` | instancji| `array<string,string>` | Serializuje kod weryfikacyjny do struktury oczekiwanej przez EFL.    |

`toRequestPayload()` zwraca tablicę z `transactionId` i `verificationCode` zmapowanymi bezpośrednio do ich nazw właściwości.

## Użycie w SDK

- Używane przez [`EflClient::postVerificationCode`](../02.efl-client/22.post-verification-code.md).
- Przekazywane do `ProcessApiClient::postVerificationCode()` jako ładunek żądania.
