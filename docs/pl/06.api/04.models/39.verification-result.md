## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Verification\VerificationResult` reprezentuje ciało (body) punktu końcowego `/Customer/LeadVerificationResult`.
Przekazuje status i wynik weryfikacji leada zainicjowanej wcześniej.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Verification`
- **Klasa**: final `VerificationResult`

```php
final class VerificationResult
{
    public static function builder(): VerificationResultBuilder;

    public ?string $status;

    public ?string $result;

    public function __construct(?string $status = null, ?string $result = null);

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa      | Typ       | Wymagane | Opis                                             |
|-----------|-----------|----------|--------------------------------------------------|
| `status`  | `string\|null` | Nie      | Status weryfikacji.                              |
| `result`  | `string\|null` | Nie      | Kod lub opis wyniku weryfikacji.                 |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `VerificationResultBuilder` | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `VerificationResult`. |
| `toRequestPayload()` | instancji| `array<string,string\|null>` | Serializuje wynik weryfikacji do struktury oczekiwanej przez EFL.    |

`toRequestPayload()` zwraca tablicę zawierającą `status` i/lub `result` tylko wtedy, gdy nie są one równe null.

## Użycie w SDK

- Używane przez [`EflClient::submitLeadVerificationResult`](../02.efl-client/15.submit-lead-verification-result.md).
- Przekazywane do `CustomerApiClient::leadVerificationResult()` jako ładunek żądania.
