## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Verification\VerificationInitializationParams` zawiera dane osobowe i adresowe wymagane do rozpoczęcia weryfikacji tożsamości w BlueMedia.
Jest wysyłany do `/Customer/InitializeIdentityVerification`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Verification`
- **Klasa**: final `VerificationInitializationParams`

```php
final class VerificationInitializationParams
{
    public static function builder(): VerificationInitializationParamsBuilder;

    public function __construct(
        string $firstName,
        string $lastName,
        string $residenceAddressStreet,
        string $residenceAddressHouseNumber,
        string $residenceAddressPostalCode,
        string $residenceAddressCity,
        string $email
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa                        | Typ      | Wymagane | Opis                                             |
|-----------------------------|----------|----------|--------------------------------------------------|
| `firstName`                 | `string` | Tak      | Imię klienta.                                    |
| `lastName`                  | `string` | Tak      | Nazwisko klienta.                                |
| `residenceAddressStreet`    | `string` | Tak      | Nazwa ulicy adresu zamieszkania.                 |
| `residenceAddressHouseNumber` | `string` | Tak      | Numer domu adresu zamieszkania.                  |
| `residenceAddressPostalCode` | `string` | Tak      | Kod pocztowy adresu zamieszkania.                |
| `residenceAddressCity`      | `string` | Tak      | Miasto adresu zamieszkania.                      |
| `email`                     | `string` | Tak      | Adres e-mail klienta.                            |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `VerificationInitializationParamsBuilder` | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `VerificationInitializationParams`. |
| `toRequestPayload()` | instancji| `array<string,string>` | Serializuje parametry weryfikacji do struktury oczekiwanej przez EFL. |

`toRequestPayload()` zwraca tablicę ze wszystkimi polami zmapowanymi bezpośrednio do ich nazw właściwości.

## Użycie w SDK

- Używane przez [`EflClient::initializeIdentityVerification`](../02.efl-client/13.initialize-identity-verification.md).
- Przekazywane do `CustomerApiClient::initializeIdentityVerification()` jako ładunek żądania.
