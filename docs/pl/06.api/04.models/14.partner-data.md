## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\PartnerData` zawiera konfigurację zwracaną przez API EFL dla kontekstu partnera transakcji.
Obecnie koncentruje się na ustawieniach związanych z UI, takich jak adres URL „powrotu do sklepu” i etykieta przycisku.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `PartnerData`

```php
final class PartnerData
{
    public ?string $returnToShopUrl;

    public ?string $returnButtonLabel;

    public function __construct(
        ?string $returnToShopUrl,
        ?string $returnButtonLabel
    );

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa               | Typ       | Wymagane | Opis                                                     |
|---------------------|-----------|----------|----------------------------------------------------------|
| `returnToShopUrl`   | `string\|null` | Nie      | Adres URL, który powinien zostać użyty do powrotu klienta do sklepu. |
| `returnButtonLabel` | `string\|null` | Nie      | Etykieta, która powinna zostać wyświetlona na przycisku powrotu. |

## Metody

| Metoda        | Rodzaj   | Typ zwracany   | Opis                                                                 |
|---------------|----------|---------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `PartnerData`  | Tworzy dane partnera z surowej odpowiedzi API, walidując i rzutując pola tekstowe. |

`fromArray()` waliduje i rzutuje pola tekstowe z odpowiedzi API.

## Użycie w SDK

- Pojawia się jako `partnerData` wewnątrz [`CalculationData`](05.calculation-data.md).
- Twoja aplikacja może używać tych wartości do konfigurowania nawigacji i etykiet przycisków w interfejsie kasy (checkout UI).
