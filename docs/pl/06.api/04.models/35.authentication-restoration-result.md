## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Restoration\AuthenticationRestorationResult` reprezentuje odpowiedź punktów końcowych przywracania, takich jak `/Restoration/RestoreCustomerSession` oraz `/Restoration/RestoreSessionAfterSigning`.
Przenosi token, identyfikator transakcji oraz enum `ReauthenticationAction` opisujący, co powinno wydarzyć się dalej.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Restoration`
- **Klasa**: final `AuthenticationRestorationResult`

```php
final class AuthenticationRestorationResult
{
    public ?string $token;

    public ?string $transactionId;

    public ReauthenticationAction $action;

    public function __construct(
        ?string $token,
        ?string $transactionId,
        ReauthenticationAction $action
    );

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa            | Typ                    | Wymagane | Opis                                             |
|-----------------|-------------------------|----------|--------------------------------------------------|
| `token`         | `string\|null`           | Nie      | Token, który może być użyty do przywrócenia sesji. |
| `transactionId` | `string\|null`           | Nie      | Identyfikator transakcji.                        |
| `action`        | `ReauthenticationAction`| Tak      | Enum opisujący następną akcję.                   |

## Metody

| Metoda        | Rodzaj   | Typ zwracany                      | Opis                                                                 |
|---------------|----------|----------------------------------|-----------------------------------------------------------------------------|
| `fromArray()` | statyczna| `AuthenticationRestorationResult` | Tworzy wynik z surowych danych API, mapując akcję na enum `ReauthenticationAction`. |

`fromArray()` odczytuje `token` i `transactionId` jako ciągi znaków, gdy są obecne, oraz mapuje `action` na wartość `ReauthenticationAction` (domyślnie `None`).

## Użycie w SDK

- Zwracane przez [`EflClient::restoreCustomerSessionByOrderId`](../02.efl-client/24.restore-customer-session-by-order-id.md).
- Zwracane przez [`EflClient::restoreSessionAfterSigning`](../02.efl-client/25.restore-session-after-signing.md).
- Twoja aplikacja może używać `action` do podjęcia decyzji, czy kontynuować płatność, wyświetlić sukces, czy nie przeprowadzać ponownego uwierzytelnienia.
