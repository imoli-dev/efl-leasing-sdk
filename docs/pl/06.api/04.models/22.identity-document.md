## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Customer\IdentityDocument` modeluje dokument tożsamości osoby, taki jak dowód osobisty lub paszport.
Jest zagnieżdżony wewnątrz [`Person`](17.person.md) w danych klienta.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Customer`
- **Klasa**: final `IdentityDocument`

```php
final class IdentityDocument
{
    public static function builder(): IdentityDocumentBuilder;

    public function __construct(
        string $guid,
        string $number,
        string $issuer,
        string $issuedOn,
        string $typeId,
        ?string $validTo = null
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa       | Typ       | Wymagane | Opis                                                     |
|-------------|-----------|----------|----------------------------------------------------------|
| `guid`      | `string`  | Tak      | Identyfikator dokumentu tożsamości.                      |
| `number`    | `string`  | Tak      | Numer dokumentu.                                         |
| `issuer`    | `string`  | Tak      | Organ wydający.                                          |
| `issuedOn`  | `string`  | Tak      | Data wydania.                                            |
| `typeId`    | `string`  | Tak      | Identyfikator typu dokumentu (np. dowód osobisty, paszport). |
| `validTo`   | `string\|null` | Nie      | Opcjonalna data ważności.                                |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `IdentityDocumentBuilder` | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `IdentityDocument`. |
| `toRequestPayload()` | instancji| `array<string,mixed>` | Serializuje dokument do struktury oczekiwanej przez API.             |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `guid`, `number`, `issuer`, `issuedOn` – mapuje się na odpowiednie właściwości,
- `type` – obiekt Descriptor z `id`, `name` oraz `version` (major, minor, patch); SDK mapuje `typeId` na pełny Descriptor z `name` równym `id` i wersją 1.0.0,
- `validTo` – uwzględniany tylko wtedy, gdy nie jest równy null.

## Użycie w SDK

- Zawarty w tablicy `identityDocuments` w [`Person`](17.person.md).
- Używany pośrednio podczas przygotowywania danych dla [`EflClient::submitCustomerData`](../02.efl-client/10.submit-customer-data.md).
