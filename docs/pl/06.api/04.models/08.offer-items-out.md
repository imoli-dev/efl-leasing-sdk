## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\OfferItemsOut` modeluje sekcję dla poszczególnych aktywów obliczonej oferty.
Jest używane wewnątrz `OfferVariant` do opisania, w jaki sposób konkretne aktywo jest finansowane w danym wariancie.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `OfferItemsOut`

```php
final class OfferItemsOut
{
    public ?int $count;

    public ?int $assetTypeId;

    public ?string $id;

    public ?AssetOfferFinancial $financing;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa         | Typ                    | Wymagane | Opis                                                     |
|---------------|-------------------------|----------|----------------------------------------------------------|
| `count`       | `int\|null`              | Nie      | Ilość aktywa w tym wariancie.                            |
| `assetTypeId` | `int\|null`              | Nie      | Identyfikator typu aktywa.                               |
| `id`          | `string\|null`           | Nie      | Identyfikator aktywa.                                    |
| `financing`   | `AssetOfferFinancial\|null` | Nie    | Rozbicie finansowe dla tego aktywa.                      |

## Metody

| Metoda        | Rodzaj   | Typ zwracany     | Opis                                                                 |
|---------------|----------|-----------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `OfferItemsOut` | Tworzy wpis aktywa z surowych danych API, rzutując pola skalarne i mapując finansowanie. |

`fromArray()` rzutuje pola skalarne, takie jak `count` i `assetTypeId`, oraz opcjonalnie mapuje `financing` na instancję `AssetOfferFinancial`.

- Pojawia się w tablicy `assets` w [`OfferVariant`](07.offer-variant.md).
- Ostatecznie używane przez konsumentów [`EflClient::calculateBasicOffer`](../02.efl-client/07.calculate-basic-offer.md) do inspekcji szczegółów na poziomie aktywów.
