## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Process\FoicProcessStateResponse` reprezentuje odpowiedź punktu końcowego `/Process/GetChanges`.
Udostępnia bieżący i przetworzony status jako enumy `EsbProcessStatus` oraz przenosi surowe ładunki `response`, `warning` i `processedResponse`, których kształt zależy od statusu.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Process`
- **Klasa**: final `FoicProcessStateResponse`

```php
final class FoicProcessStateResponse
{
    public ?string $transactionId;

    public EsbProcessStatus $status;

    /** @var mixed */
    public $response;

    /** @var mixed */
    public $warning;

    public bool $statusWasProcessed;

    /** @var mixed */
    public $processedResponse;

    public EsbProcessStatus $processedStatus;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa                | Typ             | Wymagane | Opis                                                     |
|---------------------|-----------------|----------|----------------------------------------------------------|
| `transactionId`    | `string\|null`   | Nie      | Identyfikator transakcji.                                |
| `status`           | `EsbProcessStatus` | Tak      | Bieżący status procesu.                                  |
| `response`         | `mixed`         | Tak      | Zdefiniowana przez API struktura dla bieżącego statusu.  |
| `warning`          | `mixed`         | Tak      | Zdefiniowana przez API struktura ostrzeżeń, jeśli istnieje. |
| `statusWasProcessed` | `bool`          | Tak      | Czy status został już przetworzony.                      |
| `processedResponse`| `mixed`         | Tak      | Zdefiniowana przez API struktura dla przetworzonego statusu. |
| `processedStatus`  | `EsbProcessStatus` | Tak      | Ostatni przetworzony status.                             |

Ponieważ schemat Swagger nie definiuje ścisłych typów dla `response`, `warning` i `processedResponse`, są one zachowane jako `mixed` i powinny być sprawdzane zgodnie z dokumentacją API EFL.

## Metody

| Metoda        | Rodzaj   | Typ zwracany                | Opis                                                                 |
|---------------|----------|----------------------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `FoicProcessStateResponse` | Tworzy odpowiedź z surowych danych API, mapując statusy na enumy `EsbProcessStatus`. |

`fromArray()` odczytuje `transactionId` jako ciąg znaków, mapuje `status` i `processedStatus` na wartości `EsbProcessStatus` (z powrotem do `Error` w razie potrzeby) oraz przypisuje `response`, `warning`, `processedResponse` i `statusWasProcessed` bez dalszego typowania.

## Użycie w SDK

- Zwracane przez [`EflClient::getProcessChanges`](../02.efl-client/04.get-process-changes.md).
- Twoja aplikacja może używać `status` / `processedStatus` do rozgałęziania logiki i polegać na surowym ładunku `response` w zaawansowanych scenariuszach.
