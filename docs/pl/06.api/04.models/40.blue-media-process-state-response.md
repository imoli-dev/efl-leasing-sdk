## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Verification\BlueMediaProcessStateResponse` modeluje odpowiedź z `/Customer/GetIdentityVerificationStatus`.
Udostępnia identyfikator transakcji, enum `StatusBlueMedia` oraz enum `ResultBlueMedia`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Verification`
- **Klasa**: final `BlueMediaProcessStateResponse`

```php
final class BlueMediaProcessStateResponse
{
    public function __construct(
        ?string $transactionId,
        StatusBlueMedia $status,
        ResultBlueMedia $result
    );

    public static function fromArray(array $data): self;

    public function getTransactionId(): ?string;
    public function getStatus(): StatusBlueMedia;
    public function getResult(): ResultBlueMedia;
}
```

## Właściwości

| Nazwa            | Typ               | Wymagane | Opis                                             |
|-----------------|-------------------|----------|--------------------------------------------------|
| `transactionId` | `string\|null`     | Nie      | Identyfikator transakcji, której dotyczy weryfikacja. |
| `status`        | `StatusBlueMedia` | Tak      | Bieżący status weryfikacji (np. OK, ERROR, PENDING). |
| `result`        | `ResultBlueMedia` | Tak      | Ostateczny lub bieżący wynik weryfikacji (np. POSITIVE, NEGATIVE). |

Wszystkie właściwości są dostępne poprzez metody dostępowe (getters).

## Metody

| Metoda              | Rodzaj    | Typ zwracany                    | Opis                                                                 |
|---------------------|----------|--------------------------------|-----------------------------------------------------------------------------|
| `fromArray()`       | statyczna | `BlueMediaProcessStateResponse` | Tworzy odpowiedź z surowych danych API, mapując status i wynik na enumy.    |
| `getTransactionId()`| instancji | `string\|null`              | Zwraca identyfikator transakcji.                                            |
| `getStatus()`       | instancji | `StatusBlueMedia`           | Zwraca bieżący status weryfikacji.                                          |
| `getResult()`       | instancji | `ResultBlueMedia`           | Zwraca wynik weryfikacji.                                                   |

`fromArray()` mapuje `status` na `StatusBlueMedia` (domyślnie `ERROR`) oraz `result` na `ResultBlueMedia` (domyślnie `NEGATIVE`), a także odczytuje `transactionId`, gdy jest obecny.

## Użycie w SDK

- Zwracane przez [`EflClient::getIdentityVerificationStatus`](../02.efl-client/14.get-identity-verification-status.md).
- Użyj `getStatus()` oraz `getResult()` w logice aplikacji, aby zdecydować, jak kontynuować przepływ.
