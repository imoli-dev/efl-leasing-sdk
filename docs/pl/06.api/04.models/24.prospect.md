## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Lead\Prospect` modeluje podstawowe dane leada: imię, nazwisko, identyfikator podatkowy, lokalizację, telefon i e-mail.
Jest osadzony wewnątrz [`ContactData`](23.contact-data.md).

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Lead`
- **Klasa**: final `Prospect`

```php
final class Prospect
{
    public static function builder(): ProspectBuilder;

    public function __construct(
        string $firstName,
        string $lastName,
        string $nip,
        string $postal,
        string $phoneNo,
        string $email,
        ?string $description = null
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa         | Typ       | Wymagane | Opis                                                     |
|---------------|-----------|----------|----------------------------------------------------------|
| `firstName`   | `string`  | Tak      | Imię.                                                    |
| `lastName`    | `string`  | Tak      | Nazwisko.                                                |
| `nip`         | `string`  | Tak      | Identyfikator podatkowy.                                 |
| `postal`      | `string`  | Tak      | Kod pocztowy.                                            |
| `phoneNo`     | `string`  | Tak      | Kontaktowy numer telefonu.                               |
| `email`       | `string`  | Tak      | Kontaktowy adres e-mail.                                 |
| `description` | `string\|null` | Nie      | Opcjonalny opis lub notatka w formie wolnego tekstu.     |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `ProspectBuilder`      | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `Prospect`. |
| `toRequestPayload()` | instancji| `array<string,mixed>` | Serializuje dane prospekta do struktury oczekiwanej przez EFL.       |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `firstName`, `lastName`, `nip`, `postal`, `phoneNo`, `email` – mapują się na odpowiednie właściwości,
- `description` – uwzględniany tylko wtedy, gdy nie jest równy null.

## Użycie w SDK

- Zagnieżdżony wewnątrz [`ContactData`](23.contact-data.md).
- Używany pośrednio przez [`EflClient::sendContactForm`](../02.efl-client/16.send-contact-form.md).
