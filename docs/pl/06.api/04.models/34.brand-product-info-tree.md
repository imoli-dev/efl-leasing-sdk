## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Products\BrandProductInfoTree` reprezentuje drzewo marka-model zwracane przez `/Products/GetBrandModelByProductTypeIdAndPartnerGuid`.
Zawiera identyfikator drzewa, opcjonalną datę zasilenia oraz listę węzłów `Brand` najwyższego poziomu.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Products`
- **Klasa**: final `BrandProductInfoTree`

```php
final class BrandProductInfoTree
{
    public ?string $id;

    public ?\DateTimeImmutable $feedDate;

    /** @var Brand[] */
    public array $items;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa       | Typ                    | Wymagane | Opis                                             |
|------------|-------------------------|----------|--------------------------------------------------|
| `id`       | `string\|null`           | Nie      | Identyfikator tej migawki drzewa produktów.      |
| `feedDate` | `\DateTimeImmutable\|null` | Nie      | Data zasilenia katalogu, jeśli została podana.   |
| `items`    | `Brand[]`               | Tak      | Lista marek wraz z ich modelami.                 |

## Metody

| Metoda        | Rodzaj   | Typ zwracany            | Opis                                                                 |
|---------------|--------|------------------------|-----------------------------------------------------------------------------|
| `fromArray()` | statyczna | `BrandProductInfoTree` | Tworzy drzewo z surowych danych API (identyfikator, data zasilenia i zagnieżdżone elementy marek). |

`fromArray()` odczytuje `id`, parsuje `feedDate` do `\DateTimeImmutable`, gdy to możliwe, i buduje `items` jako tablicę `Brand` za pomocą `Brand::fromArray()`.

## Użycie w SDK

- Zwracane przez [`EflClient::getBrandModelByProductType`](../02.efl-client/18.get-brand-model-by-product-type.md).
- Może być używane do obsługi selektorów marek/modeli podczas budowania koszyków i ofert.
