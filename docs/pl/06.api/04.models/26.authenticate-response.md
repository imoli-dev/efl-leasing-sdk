## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Process\AuthenticateResponse` reprezentuje odpowiedź z `/Process/GetRestoreProcess`.
Zawiera identyfikator partnera oraz token wymagany do przywrócenia istniejącej sesji procesu.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Process`
- **Klasa**: final `AuthenticateResponse`

```php
final class AuthenticateResponse
{
    public ?string $partnerId;

    public ?string $token;

    public function __construct(?string $partnerId, ?string $token);

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa        | Typ       | Wymagane | Opis                                                     |
|-------------|-----------|----------|----------------------------------------------------------|
| `partnerId` | `string\|null` | Nie      | Identyfikator partnera zwrócony przez API EFL.           |
| `token`     | `string\|null` | Nie      | Token, który może być użyty do uwierzytelnienia kolejnych żądań. |

## Metody

| Metoda        | Rodzaj   | Typ zwracany            | Opis                                                                 |
|---------------|----------|------------------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `AuthenticateResponse` | Tworzy odpowiedź z surowych danych API (identyfikator partnera i token). |

`fromArray()` odczytuje `partnerId` i `token` jako ciągi znaków, gdy są obecne, w przeciwnym razie ustawia je na null.

## Użycie w SDK

- Zwracane przez [`EflClient::getRestoreProcess`](../02.efl-client/19.get-restore-process.md).
- Może być używane do rekonstrukcji obiektu `Config` / kontekstu uwierzytelniania w Twojej aplikacji podczas przywracania procesu.
