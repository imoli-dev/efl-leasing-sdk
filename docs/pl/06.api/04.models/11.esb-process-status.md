## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\EsbProcessStatus` to PHP-owy `enum` reprezentujący wartości statusu procesu zwracane przez API EFL.
Jest używany głównie poprzez [`CalculationData`](05.calculation-data.md) do opisania stanu cyklu życia transakcji.

## Wartości

Niektóre z najważniejszych przypadków enuma:

| Wartość                      | Wartość tekstowa                      | Opis                                                     |
|------------------------------|---------------------------------------|----------------------------------------------------------|
| `TransactionInitialized`     | `'TransactionInitialized'`            | Transakcja została utworzona.                            |
| `WaitingForResponse`         | `'WaitingForResponse'`                | Oczekiwanie na odpowiedź systemu zewnętrznego.           |
| `Kalkulacja`                 | `'Kalkulacja'`                        | Obliczanie w toku.                                       |
| `FormularzNip`               | `'FormularzNIP'`                      | Krok formularza NIP.                                     |
| `DaneKontrahenta`            | `'Dane_kontrahenta'`                  | Krok wprowadzania danych klienta.                        |
| `Formularz`                  | `'Formularz'`                         | Krok formularza.                                         |
| `DecyzjaPozytywna`           | `'decyzja_pozytywna'`                 | Stan pozytywnej decyzji.                                 |
| `DecyzjaPozytywnaPowrot`     | `'Decyzja_pozytywna_powrot'`          | Stan powrotu po pozytywnej decyzji.                      |
| `End`                        | `'END'`                               | Stan końcowy.                                            |
| `TemporaryEnd`               | `'temporary_end'`                      | Tymczasowy stan końcowy.                                 |
| `ErrorEnd`                   | `'error_end'`                          | Błędny stan końcowy.                                     |
| `Error`                      | `'Error'`                             | Stan błędu.                                              |

Enum zawiera dodatkowe, bardziej szczegółowe statusy (np. `Lead`, `SlownikiWyszukiwania`, `MarkaModel`, `BmWeryfikacjaKlientaPozytywna` itp.), które odpowiadają bezpośrednio etapom procesu na backendzie.

## Użycie w SDK

- Wypełniane w [`CalculationData::fromArray`](05.calculation-data.md) na podstawie ciągu znaków statusu.
- Może być używane w logice aplikacji do rozgałęziania zachowania w zależności od bieżącego statusu procesu.
