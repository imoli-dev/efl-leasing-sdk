## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\OfferVariant` modeluje pojedynczy wariant oferty leasingowej zwrócony przez punkty końcowe obliczeń.
Zawiera parametry wysokiego poziomu, takie jak czas trwania i płatność, wraz ze szczegółami dla poszczególnych aktywów i ogólnymi podsumowaniami finansowymi.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `OfferVariant`

```php
final class OfferVariant
{
    public ?int $calculationVariantId;

    public ?int $duration;

    public ?int $payment;

    /** @var OfferItemsOut[] */
    public array $assets;

    public ?OfferFinancial $total;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa                 | Typ              | Wymagane | Opis                                                     |
|-----------------------|-------------------|----------|----------------------------------------------------------|
| `calculationVariantId`| `int\|null`        | Nie      | Identyfikator tego wariantu w ramach obliczenia.         |
| `duration`            | `int\|null`        | Nie      | Czas trwania leasingu w miesiącach.                      |
| `payment`             | `int\|null`        | Nie      | Wartość płatności (znaczenie zależy od schematu API).    |
| `assets`              | `OfferItemsOut[]`  | Tak      | Rozbicie na poszczególne aktywa dla wariantu.            |
| `total`               | `OfferFinancial\|null` | Nie    | Zagregowane dane finansowe dla wariantu.                 |

## Metody

| Metoda        | Rodzaj   | Typ zwracany   | Opis                                                                 |
|---------------|----------|---------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `OfferVariant` | Tworzy wariant z surowych danych API, wyodrębniając identyfikatory, czas trwania, płatność i budując struktury zagnieżdżone. |

`fromArray()` wyodrębnia `calculationVariantId`, `duration`, `payment`, buduje listę instancji `OfferItemsOut` z pola `assets` oraz opcjonalnie mapuje `total` na instancję `OfferFinancial`.
