## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Customer\Company` modeluje dane klienta na poziomie firmy: identyfikatory, dane kontaktowe, adresy i oświadczenia.
Jest osadzony wewnątrz [`CustomerData`](15.customer-data.md) i ostatecznie wysyłany do `/Customer/PostCustomerDataForLon`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Customer`
- **Klasa**: final `Company`

```php
final class Company
{
    public static function builder(string $guid, string $nip): CompanyBuilder;

    public function __construct(
        string $guid,
        string $nip,
        array $emails,
        array $phones,
        array $persons,
        array $addresses,
        array $statements
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa       | Typ                         | Wymagane | Opis                                                     |
|-------------|-----------------------------|----------|----------------------------------------------------------|
| `guid`      | `string`                    | Tak      | Unikalny identyfikator wpisu firmy w Twoim systemie.     |
| `nip`       | `string`                    | Tak      | Identyfikator podatkowy firmy (NIP) wymagany przez EFL.  |
| `emails`    | `EmailAddress[]`            | Tak      | Lista adresów e-mail firmy.                              |
| `phones`    | `Phone[]`                   | Tak      | Lista numerów telefonów firmy.                           |
| `persons`   | `Person[]`                  | Tak      | Osoby kontaktowe powiązane z firmą.                      |
| `addresses` | `Address[]`                 | Tak      | Adresy firmy (np. siedziba, korespondencja).             |
| `statements`| `CustomerDataStatement[]`   | Tak      | Zgody/oświadczenia złożone przez firmę.                  |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `CompanyBuilder`      | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `Company`. |
| `toRequestPayload()`| instancji| `array<string,mixed>` | Serializuje dane firmy do struktury oczekiwanej przez EFL.           |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `guid`, `nip` – mapuje się na odpowiednie właściwości,
- `emails`, `phones`, `persons`, `addresses`, `statements` – każdy element skonwertowany za pomocą własnej metody `toRequestPayload()`.

## Użycie w SDK

- Zagnieżdżony wewnątrz [`CustomerData`](15.customer-data.md).
- Budowany za pomocą `Company::builder()` w typowych przepływach przed wywołaniem [`EflClient::submitCustomerData`](../02.efl-client/10.submit-customer-data.md).
