## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Customer\EmailAddress` reprezentuje adres e‑mail powiązany z firmą lub osobą.
Jest używany wewnątrz [`Company`](16.company.md) i może być również używany dla poszczególnych osób, w zależności od użycia budowniczego.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Customer`
- **Klasa**: final `EmailAddress`

```php
final class EmailAddress
{
    public static function builder(): EmailAddressBuilder;

    public function __construct(
        string $guid,
        string $email,
        string $typeId
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa     | Typ      | Wymagane | Opis                                                     |
|-----------|----------|----------|----------------------------------------------------------|
| `guid`    | `string` | Tak      | Identyfikator wpisu e-mail.                               |
| `email`   | `string` | Tak      | Adres e-mail.                                            |
| `typeId`  | `string` | Tak      | Identyfikator typu e-mail (np. służbowy, bilingowy), mapowany na `type.id` w ładunku. |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `EmailAddressBuilder` | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `EmailAddress`. |
| `toRequestPayload()` | instancji| `array<string,mixed>` | Serializuje adres e-mail do struktury oczekiwanej przez API.         |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `guid`, `email` – mapuje się na odpowiednie właściwości,
- `type` – obiekt Descriptor z `id`, `name`, `version`; SDK mapuje `typeId` na pełny Descriptor.

## Użycie w SDK

- Używany w tablicy `emails` w [`Company`](16.company.md).
- Zawarty pośrednio w [`CustomerData`](15.customer-data.md) i wysyłany do `/Customer/PostCustomerDataForLon`.
