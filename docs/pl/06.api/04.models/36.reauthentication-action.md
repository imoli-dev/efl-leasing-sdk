## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Restoration\ReauthenticationAction` to enum wskazujący, co powinno się stać po wywołaniu przywracania.
Jest używany wewnątrz [`AuthenticationRestorationResult`](35.authentication-restoration-result.md).

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Restoration`
- **Typ**: enum `ReauthenticationAction`

```php
enum ReauthenticationAction: string
{
    case None = 'None';
    case PaymentPending = 'PaymentPending';
    case PaymentAccepted = 'PaymentAccepted';
}
```

## Wartości

| Wartość          | Wartość tekstowa    | Opis                                             |
|------------------|---------------------|--------------------------------------------------|
| `None`           | `'None'`            | Nie jest wymagana żadna dodatkowa akcja.         |
| `PaymentPending` | `'PaymentPending'`  | Płatność jest w toku i może wymagać zakończenia. |
| `PaymentAccepted`| `'PaymentAccepted'` | Płatność została zaakceptowana.                  |

## Użycie w SDK

- Interpretowane przez konsumentów [`EflClient::restoreCustomerSessionByOrderId`](../02.efl-client/24.restore-customer-session-by-order-id.md) oraz [`restoreSessionAfterSigning`](../02.efl-client/25.restore-session-after-signing.md) w celu podjęcia decyzji o dalszym postępowaniu w UI lub na backendzie.
