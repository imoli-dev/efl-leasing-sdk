## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Error\ProblemDetails` reprezentuje ustrukturyzowane informacje o błędzie zgodnie z RFC 7807.
Jest używany przez `ApiException` do udostępniania szczegółów zwracanych przez API EFL w przypadku wystąpienia błędu.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Error`
- **Klasa**: final `ProblemDetails`

```php
final class ProblemDetails
{
    public ?string $type;

    public ?string $title;

    public ?int $status;

    public ?string $detail;

    public ?string $instance;

    /** @var array<string, mixed> */
    public array $additionalProperties;

    public function __construct(array $data);

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa                 | Typ                | Wymagane | Opis                                                     |
|----------------------|---------------------|----------|----------------------------------------------------------|
| `type`               | `string\|null`       | Nie      | Odnośnik URI identyfikujący typ problemu.                |
| `title`              | `string\|null`       | Nie      | Krótkie, czytelne dla człowieka podsumowanie typu problemu. |
| `status`             | `int\|null`          | Nie      | Kod statusu HTTP mający zastosowanie do tego wystąpienia problemu. |
| `detail`             | `string\|null`       | Nie      | Czytelne dla człowieka wyjaśnienie specyficzne dla tego wystąpienia. |
| `instance`           | `string\|null`       | Nie      | Odnośnik URI identyfikujący konkretne wystąpienie problemu. |
| `additionalProperties` | `array<string,mixed>` | Tak      | Wszelkie dodatkowe dane zwrócone przez API poza standardowymi polami RFC 7807. |

## Metody

| Metoda        | Rodzaj   | Typ zwracany     | Opis                                                                 |
|---------------|----------|-----------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `ProblemDetails` | Tworzy instancję szczegółów problemu z surowych danych API (fabryka pomocnicza). |

Konstruktor wyodrębnia standardowe pola RFC 7807 (`type`, `title`, `status`, `detail`, `instance`) i zachowuje wszystkie dodatkowe klucze w tablicy `additionalProperties`.

## Użycie w SDK

- Dostępne przez `ApiException::getProblemDetails()`.
- Powinno być logowane lub sprawdzane przez aplikację podczas obsługi błędów API.
- W połączeniu z kodem statusu HTTP pozwala na podjęcie decyzji o strategii obsługi błędów (np. ponowienie próby vs błąd walidacji dla użytkownika).
