## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\CalculationData` reprezentuje ciało odpowiedzi (response body) punktu końcowego `/Calculation/GetBaseData`.
Łączy status procesu, surowe dane koszyka, wynik obliczeń, konfigurację partnera i adresy URL przekierowań.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `CalculationData`

```php
final class CalculationData
{
    public EsbProcessStatus $status;

    /** @var array<string, mixed>|null */
    public ?array $basket;

    public ?EsbCalculateBasicOfferRestReturn $calculation;

    public ?int $calculationVariantId;

    public ?PartnerData $partnerData;

    public ?string $returnToBasketUrl;

    public ?string $signProcessRedirectUrl;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa                     | Typ                               | Wymagane | Opis                                                     |
|---------------------------|-----------------------------------|----------|----------------------------------------------------------|
| `status`                  | `EsbProcessStatus`                | Tak      | Bieżący status procesu.                                  |
| `basket`                  | `array<string,mixed>\|null`        | Nie      | Surowa struktura koszyka zwrócona przez API.             |
| `calculation`             | `EsbCalculateBasicOfferRestReturn\|null` | Nie   | Szczegółowy wynik obliczeń, jeśli jest obecny.           |
| `calculationVariantId`    | `int\|null`                        | Nie      | Identyfikator wybranego wariantu, jeśli istnieje.        |
| `partnerData`             | `PartnerData\|null`                | Nie      | Konfiguracja specyficzna dla partnera (np. adres URL powrotu, etykieta przycisku). |
| `returnToBasketUrl`       | `string\|null`                     | Nie      | Adres URL powrotu do widoku koszyka.                     |
| `signProcessRedirectUrl`  | `string\|null`                     | Nie      | Adres URL do przejścia do procesu podpisywania.          |

## Metody

| Metoda        | Rodzaj   | Typ zwracany        | Opis                                                                 |
|---------------|----------|---------------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `CalculationData`   | Tworzy dane obliczeń z surowej odpowiedzi API, mapując status na enum i struktury zagnieżdżone. |

`fromArray()` mapuje `status` na enum `EsbProcessStatus`, opcjonalnie mapuje `calculation` na `EsbCalculateBasicOfferRestReturn`, opcjonalnie mapuje `partnerData` na `PartnerData` oraz wyodrębnia pola ID i URL.

## Użycie w SDK

- Zwracane przez [`EflClient::getBaseData`](../02.efl-client/08.get-base-data.md).
- Może być używane do wyświetlania wariantów obliczeń, wskazówek UI partnera i adresów URL przekierowań w Twojej aplikacji.
