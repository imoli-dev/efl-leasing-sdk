## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Products\Sector` reprezentuje węzeł sektora w katalogu produktów EFL.
Każdy sektor grupuje jedną lub więcej klas produktów (`ProductClass`), które z kolei zawierają typy produktów.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Products`
- **Klasa**: final `Sector`

```php
final class Sector
{
    public ?string $name;

    public int $id;

    /** @var ProductClass[] */
    public array $classes;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa      | Typ             | Wymagane | Opis                                             |
|-----------|-----------------|----------|--------------------------------------------------|
| `name`    | `string\|null`   | Nie      | Nazwa sektora.                                   |
| `id`      | `int`           | Tak      | Identyfikator sektora.                           |
| `classes` | `ProductClass[]`| Tak      | Lista klas produktów w tym sektorze.             |

## Metody

| Metoda        | Rodzaj   | Typ zwracany | Opis                                                                 |
|---------------|----------|-------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `Sector`     | Tworzy sektor z surowych danych API (nazwa, identyfikator i zagnieżdżone klasy produktów). |

`fromArray()` odczytuje `name` jako ciąg znaków, rzutuje `id` na liczbę całkowitą i buduje `classes` z tablicy zagnieżdżonych struktur za pomocą `ProductClass::fromArray()`.

## Użycie w SDK

- Używane wewnątrz [`SectorProductInfoTree`](33.sector-product-info-tree.md) do reprezentowania hierarchicznego katalogu produktów.
- Zwracane pośrednio przez [`EflClient::getSectorClassAndType`](../02.efl-client/17.get-sector-class-and-type.md).
