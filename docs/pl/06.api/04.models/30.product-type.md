## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Products\ProductType` reprezentuje pojedynczy typ produktu w katalogu produktów EFL.
Przenosi identyfikator typu, stawkę VAT oraz flagę `recommended`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Products`
- **Klasa**: final `ProductType`

```php
final class ProductType
{
    public ?string $name;

    public int $id;

    public float $vatRate;

    public bool $recommended;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa          | Typ         | Wymagane | Opis                                                     |
|---------------|-------------|----------|----------------------------------------------------------|
| `name`        | `string\|null` | Nie      | Nazwa typu produktu.                                     |
| `id`          | `int`       | Tak      | Identyfikator typu produktu używany w innych wywołaniach API. |
| `vatRate`     | `float`     | Tak      | Stawka VAT mająca zastosowanie do tego typu.             |
| `recommended` | `bool`      | Tak      | Czy ten typ jest rekomendowany.                          |

## Metody

| Metoda        | Rodzaj   | Typ zwracany   | Opis                                                                 |
|---------------|----------|---------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `ProductType` | Tworzy typ produktu z surowych danych API (nazwa, identyfikator, stawka VAT i flaga rekomendacji). |

`fromArray()` odczytuje `name` jako ciąg znaków, rzutuje `id` na int, `vatRate` na float i `recommended` na bool.

## Użycie w SDK

- Używane przez [`EflClient::getBrandModelByProductType`](../02.efl-client/18.get-brand-model-by-product-type.md) podczas żądania informacji o marce/modelu dla danego typu.
