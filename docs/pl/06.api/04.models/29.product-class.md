## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Products\ProductClass` grupuje typy produktów (`ProductType`) w ramach sektora.
Jest częścią hierarchicznej struktury zwracanej przez punkty końcowe katalogu produktów.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Products`
- **Klasa**: final `ProductClass`

```php
final class ProductClass
{
    public ?string $name;

    /** @var ProductType[] */
    public array $productTypes;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa          | Typ             | Wymagane | Opis                                             |
|---------------|-----------------|----------|--------------------------------------------------|
| `name`        | `string\|null`   | Nie      | Nazwa klasy (np. kategoria aktywów).             |
| `productTypes`| `ProductType[]` | Tak      | Lista typów produktów w tej klasie.              |

## Metody

| Metoda        | Rodzaj   | Typ zwracany   | Opis                                                                 |
|---------------|----------|---------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `ProductClass` | Tworzy klasę produktu z surowych danych API (nazwa i zagnieżdżone typy produktów). |

`fromArray()` odczytuje `name` jako ciąg znaków i buduje `productTypes` z tablicy za pomocą `ProductType::fromArray()`.

## Użycie w SDK

- Zagnieżdżony wewnątrz [`Sector`](28.sector.md) oraz [`SectorProductInfoTree`](33.sector-product-info-tree.md).
- Zwracane pośrednio przez [`EflClient::getSectorClassAndType`](../02.efl-client/17.get-sector-class-and-type.md).
