## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Verification\ResultBlueMedia` to enum reprezentujący możliwe wyniki weryfikacji BlueMedia.
Jest używany wewnątrz [`BlueMediaProcessStateResponse`](40.blue-media-process-state-response.md).

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Verification`
- **Typ**: enum `ResultBlueMedia`

```php
enum ResultBlueMedia: string
{
    case Positive = 'POSITIVE';
    case Negative = 'NEGATIVE';
    case Abandoned = 'ABANDONED';
    case RejectedByUser = 'REJECTED_BY_USER';
}
```

## Wartości

| Wartość          | Wartość tekstowa       | Opis                                                     |
|------------------|------------------------|----------------------------------------------------------|
| `Positive`       | `'POSITIVE'`           | Weryfikacja zakończyła się sukcesem.                     |
| `Negative`       | `'NEGATIVE'`           | Weryfikacja nie powiodła się.                            |
| `Abandoned`      | `'ABANDONED'`          | Proces został porzucony.                                 |
| `RejectedByUser` | `'REJECTED_BY_USER'`   | Weryfikacja została wyraźnie odrzucona przez użytkownika. |

## Użycie w SDK

- Zwracane przez `BlueMediaProcessStateResponse::getResult()`.
- Używane w połączeniu z `StatusBlueMedia` do interpretacji stanu weryfikacji w Twojej aplikacji.
