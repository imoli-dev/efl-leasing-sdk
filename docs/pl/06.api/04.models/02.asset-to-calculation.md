## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\AssetToCalculation` reprezentuje ciało (body) wysyłane do punktu końcowego `/Calculation/CalculateBasicOffer`.
Przechowuje identyfikator transakcji, listę wpisów `OfferItem` oraz opcjonalne pola kontrolujące zachowanie obliczeń koszyka.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `AssetToCalculation`

```php
final class AssetToCalculation
{
    public static function builder(string $transactionId): AssetToCalculationBuilder;

    public function __construct(
        string $transactionId,
        array $offerItems,
        ?string $returnToBasketUrl = null,
        ?bool $basketCalculation = null
    );

    public function getOfferItems(): array;
    public function getTransactionId(): string;
    public function getReturnToBasketUrl(): ?string;
    public function isBasketCalculation(): ?bool;
    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa               | Typ           | Wymagane | Opis                                                     |
|---------------------|---------------|----------|----------------------------------------------------------|
| `transactionId`     | `string`      | Tak      | Identyfikator bieżącej transakcji.                       |
| `offerItems`       | `OfferItem[]` | Tak      | Lista elementów uwzględnionych w obliczeniach.           |
| `returnToBasketUrl`| `string\|null` | Nie      | Opcjonalny adres URL do przekierowania użytkownika z powrotem do koszyka. |
| `basketCalculation`| `bool\|null`   | Nie      | Wskazuje, czy obliczenia są wykonywane dla całego koszyka. |

## Metody

| Metoda                  | Rodzaj   | Typ zwracany          | Opis                                                                 |
|-------------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`             | statyczna| `AssetToCalculationBuilder` | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `AssetToCalculation`. |
| `getOfferItems()`       | instancji| `OfferItem[]`         | Zwraca listę elementów oferty.                                       |
| `getTransactionId()`    | instancji| `string`               | Zwraca identyfikator transakcji.                                     |
| `getReturnToBasketUrl()`| instancji| `string\|null`         | Zwraca adres URL powrotu do koszyka, jeśli został ustawiony.         |
| `isBasketCalculation()` | instancji| `bool\|null`           | Zwraca informację, czy obliczenia koszykowe są włączone.             |
| `toRequestPayload()`    | instancji| `array<string,mixed>`  | Serializuje żądanie obliczenia do struktury oczekiwanej przez EFL.   |

`toRequestPayload()` zwraca tablicę z `transactionId`, `offerItems` (każdy skonwertowany przez `OfferItem::toRequestPayload()`) oraz opcjonalnie `returnToBasketUrl` i `basketCalculation`, gdy nie są one równe null.

## Użycie w SDK

- Używane przez [`EflClient::calculateBasicOffer`](../02.efl-client/07.calculate-basic-offer.md).
- Przekazywane do `CalculationApiClient::calculateBasicOffer()` jako ładunek żądania (request payload).
