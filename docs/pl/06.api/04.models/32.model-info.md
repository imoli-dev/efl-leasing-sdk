## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Products\ModelInfo` reprezentuje pojedynczy wpis modelu w ramach marki.
Zawiera nazwę modelu oraz opcjonalną informację o typie aktywa.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Products`
- **Klasa**: final `ModelInfo`

```php
final class ModelInfo
{
    public ?string $name;

    public ?string $assetType;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa        | Typ        | Wymagane | Opis                                             |
|-------------|-------------|----------|--------------------------------------------------|
| `name`      | `string\|null` | Nie      | Nazwa modelu.                                    |
| `assetType` | `string\|null` | Nie      | Opcjonalna klasyfikacja typu aktywa.             |

## Metody

| Metoda        | Rodzaj   | Typ zwracany | Opis                                                                 |
|---------------|----------|-------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `ModelInfo`  | Tworzy wpis informacji o modelu z surowych danych API (nazwa i opcjonalny typ aktywa). |

`fromArray()` odczytuje `name` i `assetType` jako ciągi znaków.

## Użycie w SDK

- Zagnieżdżony wewnątrz [`Brand`](31.brand.md) i ostatecznie w [`BrandProductInfoTree`](34.brand-product-info-tree.md).
- Zwracane pośrednio przez [`EflClient::getBrandModelByProductType`](../02.efl-client/18.get-brand-model-by-product-type.md).
