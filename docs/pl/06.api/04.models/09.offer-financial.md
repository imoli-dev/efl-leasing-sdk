## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\OfferFinancial` reprezentuje ogólne rozbicie finansowe wariantu oferty leasingowej.
Zawiera wartości oferty netto/brutto, wartości końcowe oraz opcjonalne komponenty dla czystego finansowania i ubezpieczenia.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `OfferFinancial`

```php
final class OfferFinancial
{
    public ?float $netResidualValuePercent;
    public ?float $recommendedPrice;
    public ?float $netResidualValue;
    public ?float $netInitialPayment;
    public ?float $grossOfferValue;
    public ?float $partnerGrossOfferValue;
    public ?float $grossResidualValue;
    public ?float $netInitialResidualValue;
    public float $netOfferValue;
    public float $netLastRentResidualValue;
    public ?float $grossResidualValuePercent;
    public ?float $grossInitialPayment;
    public ?FinancialPure $pure;
    public ?FinancialInsurance $insurance;
    public ?float $calculatedNetInstallmentValue;
    public ?float $calculatedGrossInstallmentValue;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa                         | Typ                    | Wymagane | Opis                                                     |
|-------------------------------|-------------------------|----------|----------------------------------------------------------|
| `netResidualValuePercent`     | `float\|null`            | Nie      | Wartość końcowa netto jako procent.                      |
| `recommendedPrice`             | `float\|null`            | Nie      | Rekomendowana cena aktywa.                               |
| `netResidualValue`            | `float\|null`            | Nie      | Kwota wartości końcowej netto.                           |
| `netInitialPayment`           | `float\|null`            | Nie      | Wpłata początkowa netto.                                 |
| `grossOfferValue`             | `float\|null`            | Nie      | Wartość oferty brutto.                                   |
| `partnerGrossOfferValue`      | `float\|null`            | Nie      | Wartość oferty brutto z perspektywy partnera.            |
| `grossResidualValue`          | `float\|null`            | Nie      | Wartość końcowa brutto.                                  |
| `netInitialResidualValue`     | `float\|null`            | Nie      | Początkowa wartość końcowa netto.                        |
| `netOfferValue`              | `float`                 | Tak      | Wartość netto oferty.                                    |
| `netLastRentResidualValue`    | `float`                 | Tak      | Wartość końcowa ostatniego czynszu.                      |
| `grossResidualValuePercent`   | `float\|null`            | Nie      | Wartość końcowa brutto jako procent.                     |
| `grossInitialPayment`         | `float\|null`            | Nie      | Wpłata początkowa brutto.                                |
| `pure`                        | `FinancialPure\|null`    | Nie      | Rozbicie czystego finansowania.                          |
| `insurance`                   | `FinancialInsurance\|null` | Nie     | Finanse związane z ubezpieczeniem.                       |
| `calculatedNetInstallmentValue` | `float\|null`          | Nie      | Wartość raty netto obliczona przez API.                  |
| `calculatedGrossInstallmentValue` | `float\|null`        | Nie      | Wartość raty brutto obliczona przez API.                 |

## Metody

| Metoda        | Rodzaj   | Typ zwracany       | Opis                                                                 |
|---------------|----------|------------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `OfferFinancial`  | Tworzy dane finansowe z surowej odpowiedzi API, rzutując pola numeryczne i mapując struktury zagnieżdżone. |

`fromArray()` rzutuje liczne pola skalarne na typ float i opcjonalnie konstruuje `FinancialPure` oraz `FinancialInsurance` z tablic zagnieżdżonych.

## Użycie w SDK

- Dołączone jako `total` w [`OfferVariant`](07.offer-variant.md).
- Dostarcza szczegółowe kwoty, które mogą być prezentowane w UI lub używane do rozliczeń.
