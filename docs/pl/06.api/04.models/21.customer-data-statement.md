## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Customer\CustomerDataStatement` modeluje wpis oświadczenia/zgody dołączony do danych klienta.
Może być powiązany z firmą (`Company::toRequestPayload()`) lub osobą (`Person::toRequestPayload()`).

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Customer`
- **Klasa**: final `CustomerDataStatement`

```php
final class CustomerDataStatement
{
    public static function builder(): CustomerDataStatementBuilder;

    public function __construct(
        string $guid,
        bool $agreement,
        string $statementTypeId,
        ?string $validFrom = null
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa              | Typ       | Wymagane | Opis                                                     |
|-------------------|-----------|----------|----------------------------------------------------------|
| `guid`            | `string`  | Tak      | Unikalny identyfikator oświadczenia.                     |
| `agreement`       | `bool`    | Tak      | Flaga wskazująca, czy oświadczenie zostało zaakceptowane. |
| `statementTypeId` | `string`  | Tak      | Identyfikator typu używany przez EFL.                    |
| `validFrom`       | `string\|null` | Nie      | Opcjonalna data rozpoczęcia obowiązywania oświadczenia.   |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `CustomerDataStatementBuilder` | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `CustomerDataStatement`. |
| `toRequestPayload()` | instancji| `array<string,mixed>` | Serializuje oświadczenie do struktury oczekiwanej przez API.         |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `guid`, `agreement` – mapuje się na odpowiednie właściwości,
- `statementType` – obiekt Descriptor z `id`, `name`, `version`; SDK mapuje `statementTypeId` na pełny Descriptor,
- `validFrom` – uwzględniany tylko wtedy, gdy nie jest równy null.

## Użycie w SDK

- Zawarty w tablicy `statements` w [`Company`](16.company.md).
- Opcjonalnie zawarty w `Person` jako oświadczenia na poziomie osoby.
- Używany pośrednio przez [`EflClient::submitCustomerData`](../02.efl-client/10.submit-customer-data.md) oraz [`submitCustomerStatements`](../02.efl-client/11.submit-customer-statements.md).
