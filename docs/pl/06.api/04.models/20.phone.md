## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Customer\Phone` reprezentuje numer telefonu z prefiksem oraz informacją o typie/rodzaju.
Jest używany wewnątrz [`Company`](16.company.md) podczas budowania danych klienta.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Customer`
- **Klasa**: final `Phone`

```php
final class Phone
{
    public static function builder(): PhoneBuilder;

    public function __construct(
        string $guid,
        string $prefix,
        string $number,
        string $typeId,
        string $kindId,
    );

    public function toRequestPayload(): array;
}
```

Klasa używa prywatnych właściwości z pojedynczą metodą `toRequestPayload()`, aby udostępnić je jako tablicę dla żądań HTTP.

## Właściwości

| Nazwa     | Typ      | Wymagane | Opis                                                    |
| --------- | -------- | -------- | ------------------------------------------------------- |
| `guid`    | `string` | Tak      | Identyfikator wpisu telefonu.                           |
| `prefix`  | `string` | Tak      | Prefiks kraju lub obszaru (np. `+48`).                  |
| `number`  | `string` | Tak      | Numer telefonu.                                         |
| `typeId`  | `string` | Tak      | Id typu telefonu (`type.id` w ładunku, np. komórkowy).  |
| `kindId`  | `string` | Tak      | Id rodzaju/kategorii (`kind.id` w ładunku, np. służbowy). |

Wszystkie właściwości są wymagane przez konstruktor i muszą zostać podane podczas tworzenia instancji `Phone`.

## Metody

| Metoda               | Rodzaj    | Typ zwracany          | Opis                                                               |
| -------------------- | --------- | --------------------- | ------------------------------------------------------------------ |
| `builder()`          | statyczna | `PhoneBuilder`        | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `Phone`. |
| `toRequestPayload()` | instancji | `array<string,mixed>` | Serializuje dane telefonu do struktury tablicowej oczekiwanej przez EFL. |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `guid` – mapuje się na właściwość `guid`,
- `prefix` – mapuje się na właściwość `prefix`,
- `number` – mapuje się na właściwość `number`,
- `type` – obiekt Descriptor z `id`, `name`, `version`; SDK mapuje `typeId` na pełny Descriptor,
- `kind` – obiekt Descriptor; SDK mapuje `kindId` na pełny Descriptor.

## Użycie w SDK

- Używany w tablicy `phones` w [`Company`](16.company.md).
- Zawarty pośrednio w [`CustomerData`](15.customer-data.md) dla `/Customer/PostCustomerDataForLon`.
