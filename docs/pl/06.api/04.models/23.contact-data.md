## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Lead\ContactData` reprezentuje ciało (body) punktu końcowego `/Lead/SendContactForm`.
Zawiera obiekt `Prospect` (szczegóły leada) oraz listę wpisów `StatementLead` opisujących zgody.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Lead`
- **Klasa**: final `ContactData`

```php
final class ContactData
{
    public static function builder(): ContactDataBuilder;

    public function __construct(
        Prospect $prospect,
        array $statementLeads
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa           | Typ               | Wymagane | Opis                                                     |
|-----------------|-------------------|----------|----------------------------------------------------------|
| `prospect`      | `Prospect`        | Tak      | Informacje o leadzie/prospekcie (imię, nazwisko, NIP, dane kontaktowe). |
| `statementLeads`| `StatementLead[]` | Tak      | Lista oświadczeń/zgód specyficznych dla leada.           |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `ContactDataBuilder`  | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `ContactData`. |
| `toRequestPayload()` | instancji| `array<string,mixed>` | Serializuje dane kontaktowe do struktury oczekiwanej przez EFL.      |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `prospect` – ładunek z `Prospect::toRequestPayload()`,
- `statementLead` – tablica ładunków z `StatementLead::toRequestPayload()`.

## Użycie w SDK

- Używane przez [`EflClient::sendContactForm`](../02.efl-client/16.send-contact-form.md).
- Przekazywane do `LeadApiClient::sendContactForm()` jako ładunek żądania.
