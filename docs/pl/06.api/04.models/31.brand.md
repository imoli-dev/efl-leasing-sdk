## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Products\Brand` modeluje wpis marki w katalogu produktów EFL.
Przechowuje nazwę marki oraz tablicę elementów `ModelInfo`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Products`
- **Klasa**: final `Brand`

```php
final class Brand
{
    public ?string $name;

    /** @var ModelInfo[] */
    public array $models;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa     | Typ           | Wymagane | Opis                                             |
|----------|---------------|----------|--------------------------------------------------|
| `name`   | `string\|null` | Nie      | Nazwa marki.                                     |
| `models` | `ModelInfo[]` | Tak      | Lista modeli powiązanych z tą marką.             |

## Metody

| Metoda        | Rodzaj   | Typ zwracany | Opis                                                                 |
|---------------|----------|-------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `Brand`      | Tworzy markę z surowych danych API (nazwa i zagnieżdżone informacje o modelu). |

`fromArray()` odczytuje `name` jako ciąg znaków i buduje `models` z zagnieżdżonych tablic za pomocą `ModelInfo::fromArray()`.

## Użycie w SDK

- Zagnieżdżony wewnątrz [`BrandProductInfoTree`](34.brand-product-info-tree.md).
- Zwracane pośrednio przez [`EflClient::getBrandModelByProductType`](../02.efl-client/18.get-brand-model-by-product-type.md).
