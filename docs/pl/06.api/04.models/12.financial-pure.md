## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\FinancialPure` przechowuje część oferty dotyczącą czystego finansowania: kwoty rat i podsumowania z wyłączeniem ubezpieczenia.
Jest zagnieżdżony wewnątrz [`OfferFinancial`](09.offer-financial.md) oraz [`AssetOfferFinancial`](10.asset-offer-financial.md).

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `FinancialPure`

```php
final class FinancialPure
{
    public ?float $netInstallmentAmount;
    public ?float $vatInstallmentAmount;
    public ?float $grossInstallmentAmount;
    public ?float $netTotalAmount;
    public ?float $grossTotalAmount;
    public ?float $netResidualInstallmentAmount;

    public function __construct(
        ?float $netInstallmentAmount,
        ?float $vatInstallmentAmount,
        ?float $grossInstallmentAmount,
        ?float $netTotalAmount,
        ?float $grossTotalAmount,
        ?float $netResidualInstallmentAmount
    );

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa                         | Typ         | Wymagane | Opis                                                     |
|-------------------------------|-------------|----------|----------------------------------------------------------|
| `netInstallmentAmount`        | `float\|null`| Nie      | Kwota netto pojedynczej raty.                            |
| `vatInstallmentAmount`       | `float\|null`| Nie      | Część VAT raty.                                          |
| `grossInstallmentAmount`      | `float\|null`| Nie      | Kwota brutto raty.                                       |
| `netTotalAmount`              | `float\|null`| Nie      | Całkowita kwota netto dla całego harmonogramu.          |
| `grossTotalAmount`            | `float\|null`| Nie      | Całkowita kwota brutto dla całego harmonogramu.         |
| `netResidualInstallmentAmount`| `float\|null`| Nie      | Kwota netto raty końcowej.                               |

| `fromArray()` | statyczna| `FinancialPure`  | Tworzy dane czystego finansowania z surowej odpowiedzi API, rzutując pola numeryczne. |

## Użycie w SDK

- Używane jako `pure` w [`OfferFinancial`](09.offer-financial.md) oraz [`AssetOfferFinancial`](10.asset-offer-financial.md).
