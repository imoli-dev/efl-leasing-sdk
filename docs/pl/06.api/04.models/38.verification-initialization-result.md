## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Verification\VerificationInitializationResult` reprezentuje odpowiedź z `/Customer/InitializeIdentityVerification`.
Zawiera status, opcjonalny opis, adres URL przekierowania oraz UUID zamówienia.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Verification`
- **Klasa**: final `VerificationInitializationResult`

```php
final class VerificationInitializationResult
{
    public function __construct(
        ?string $status,
        ?string $description,
        ?string $redirectUrl,
        ?string $orderUuid
    );

    public static function fromArray(array $data): self;

    public function getStatus(): ?string;
    public function getDescription(): ?string;
    public function getRedirectUrl(): ?string;
    public function getOrderUuid(): ?string;
}
```

## Właściwości

| Nazwa          | Typ       | Wymagane | Opis                                             |
|---------------|-----------|----------|--------------------------------------------------|
| `status`      | `string\|null` | Nie      | Status żądania inicjalizacji.                    |
| `description` | `string\|null` | Nie      | Opcjonalny opis czytelny dla człowieka.          |
| `redirectUrl` | `string\|null` | Nie      | Adres URL, na który klient powinien zostać przekierowany w celu przeprowadzenia weryfikacji. |
| `orderUuid`   | `string\|null` | Nie      | Identyfikator zamówienia weryfikacji.            |

Wszystkie właściwości są dostępne poprzez metody dostępowe (getters).

## Metody

| Metoda              | Rodzaj    | Typ zwracany                    | Opis                                                                 |
|---------------------|---------|--------------------------------|-----------------------------------------------------------------------------|
| `fromArray()`       | statyczna | `VerificationInitializationResult` | Tworzy wynik z surowych danych API (status, opis, adres URL przekierowania, UUID zamówienia). |
| `getStatus()`       | instancji | `string\|null`              | Zwraca status.                                                              |
| `getDescription()`   | instancji | `string\|null`              | Zwraca opis.                                                                |
| `getRedirectUrl()`  | instancji | `string\|null`              | Zwraca adres URL przekierowania.                                            |
| `getOrderUuid()`    | instancji | `string\|null`              | Zwraca UUID zamówienia.                                                     |

## Użycie w SDK

- Zwracane przez [`EflClient::initializeIdentityVerification`](../02.efl-client/13.initialize-identity-verification.md).
- Twoja aplikacja powinna przekierować klienta pod adres `redirectUrl` i zapisać `orderUuid` do późniejszego sprawdzania statusu.
