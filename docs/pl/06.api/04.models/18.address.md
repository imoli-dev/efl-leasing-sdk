## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Customer\Address` reprezentuje ustrukturyzowany adres pocztowy używany w danych klienta i firmy.
Jest używany wewnątrz [`Company`](16.company.md) oraz [`Person`](17.person.md) podczas tworzenia `CustomerData`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Customer`
- **Klasa**: final `Address`

```php
final class Address
{
    public static function builder(): AddressBuilder;

    public function __construct(
        string $guid,
        string $name,
        string $typeId,
        string $city,
        string $street,
        string $houseNumber,
        string $postalCode,
        string $countryCode,
        ?string $flatNumber = null
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa         | Typ       | Wymagane | Opis                                                     |
|---------------|-----------|----------|----------------------------------------------------------|
| `guid`        | `string`  | Tak      | Unikalny identyfikator wpisu adresu.                     |
| `name`        | `string`  | Tak      | Czytelna dla człowieka nazwa/etykieta adresu (np. „Siedziba”). |
| `typeId`      | `string`  | Tak      | Identyfikator typu adresu (np. siedziba, korespondencja). |
| `city`        | `string`  | Tak      | Nazwa miasta.                                            |
| `street`      | `string`  | Tak      | Nazwa ulicy.                                             |
| `houseNumber` | `string`  | Tak      | Numer domu/budynku.                                      |
| `postalCode`  | `string`  | Tak      | Kod pocztowy.                                            |
| `countryCode` | `string`  | Tak      | Kod kraju zgodny z ISO.                                  |
| `flatNumber`  | `string\|null` | Nie    | Opcjonalny numer mieszkania/lokalu.                      |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `AddressBuilder`      | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `Address`. |
| `toRequestPayload()` | instancji| `array<string,mixed>` | Serializuje adres do struktury oczekiwanej przez API.                |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `guid`, `name` – mapuje się na odpowiednie właściwości,
- `type` – obiekt Descriptor z `id`, `name`, `version`; SDK mapuje `typeId` na pełny Descriptor,
- `city`, `street`, `houseNumber` – mapuje się na odpowiednie właściwości,
- `postal` – obiekt Descriptor; SDK mapuje `postalCode` na pełny Descriptor,
- `country` – obiekt Descriptor; SDK mapuje `countryCode` na pełny Descriptor,
- `flatNumber` – uwzględniany tylko wtedy, gdy nie jest równy null.

## Użycie w SDK

- Używany w tablicy `addresses` w [`Company`](16.company.md).
- Używany jako właściwość `address` w [`Person`](17.person.md).
- Używany pośrednio podczas wywoływania [`EflClient::submitCustomerData`](../02.efl-client/10.submit-customer-data.md).
