## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Products\SectorProductInfoTree` reprezentuje hierarchiczny katalog produktów zwracany przez `/Products/GetSectorClassAndType`.
Zawiera identyfikator drzewa, opcjonalną datę zasilenia oraz listę węzłów `Sector` najwyższego poziomu.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Products`
- **Klasa**: final `SectorProductInfoTree`

```php
final class SectorProductInfoTree
{
    public ?string $id;

    public ?\DateTimeImmutable $feedDate;

    /** @var Sector[] */
    public array $items;

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa       | Typ                    | Wymagane | Opis                                             |
|-----------|-------------------------|----------|--------------------------------------------------|
| `id`      | `string\|null`           | Nie      | Identyfikator tej migawki drzewa produktów.      |
| `feedDate`| `\DateTimeImmutable\|null` | Nie      | Data zasilenia katalogu, jeśli została podana.   |
| `items`   | `Sector[]`              | Tak      | Lista głównych węzłów sektorów w drzewie katalogu. |

## Metody

| Metoda         | Rodzaj    | Typ zwracany                | Opis                                                                 |
|----------------|---------|----------------------------|-----------------------------------------------------------------------------|
| `fromArray()`  | statyczna  | `SectorProductInfoTree`    | Tworzy drzewo z surowych danych API (identyfikator, data zasilenia i zagnieżdżone elementy sektorów). |

`fromArray()` odczytuje `id`, parsuje `feedDate` do `\DateTimeImmutable`, gdy to możliwe, i buduje `items` jako tablicę instancji `Sector` za pomocą `Sector::fromArray()`.

## Użycie w SDK

- Zwracane przez [`EflClient::getSectorClassAndType`](../02.efl-client/17.get-sector-class-and-type.md).
- Może być używane do obsługi interfejsów wyboru produktów dla sektorów, klas i typów produktów.
