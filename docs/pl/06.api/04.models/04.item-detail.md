## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\ItemDetail` przechowuje pojedynczą parę klucz-wartość metadanych dla `OfferItem`.
Służy do wzbogacania żądań obliczeń o ustrukturyzowane atrybuty wymagane przez API EFL.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `ItemDetail`

```php
final class ItemDetail
{
    public static function builder(): ItemDetailBuilder;

    public function __construct(
        string $id,
        string $value
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa   | Typ      | Wymagane | Opis                                                     |
|---------|----------|----------|----------------------------------------------------------|
| `id`    | `string` | Tak      | Identyfikator szczegółu (np. kod zdefiniowany przez EFL lub Twój system). |
| `value` | `string` | Tak      | Tekstowa reprezentacja wartości szczegółu.               |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `ItemDetailBuilder`   | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `ItemDetail`. |
| `toRequestPayload()` | instancji| `array{id:string,value:string}` | Serializuje szczegół do struktury oczekiwanej przez EFL.             |

`toRequestPayload()` zwraca tablicę z `id` i `value` zmapowanymi bezpośrednio do ich nazw właściwości.

## Użycie w SDK

- Używane w `OfferItem` (`OfferItem::toRequestPayload()`) jako część tablicy `itemDetails`.
- Używane pośrednio przez [`EflClient::calculateBasicOffer`](../02.efl-client/07.calculate-basic-offer.md) podczas budowania żądań obliczeń.
