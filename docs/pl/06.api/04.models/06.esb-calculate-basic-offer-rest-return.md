## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\EsbCalculateBasicOfferRestReturn` modeluje odpowiedź punktu końcowego `/Calculation/CalculateBasicOffer`.
Agreguje metadane o obliczeniu oraz listę instancji `OfferVariant`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `EsbCalculateBasicOfferRestReturn`

```php
final class EsbCalculateBasicOfferRestReturn
{
    public ?string $transactionId;

    public ?int $calculationId;

    public ?\DateTimeImmutable $calculationTimestamp;

    /** @var OfferVariant[] */
    public array $variants;

    public bool $basketCalculation;

    public static function fromArray(array $data): self;

    public static function emptyForTransaction(string $transactionId): self;
}
```

## Właściwości

| Nazwa                 | Typ                     | Wymagane | Opis                                                     |
|-----------------------|-------------------------|----------|----------------------------------------------------------|
| `transactionId`       | `string\|null`           | Nie      | Identyfikator transakcji, dla której wykonano obliczenie. |
| `calculationId`      | `int\|null`              | Nie      | Wewnętrzny identyfikator obliczenia.                     |
| `calculationTimestamp`| `\DateTimeImmutable\|null` | Nie     | Znacznik czasu obliczenia, jeśli jest możliwy do sparsowania. |
| `variants`            | `OfferVariant[]`        | Tak      | Lista dostępnych wariantów oferty.                       |
| `basketCalculation`   | `bool`                  | Tak      | Czy obliczenie zostało wykonane dla całego koszyka.      |

## Metody

| Metoda                 | Rodzaj   | Typ zwracany                      | Opis                                                                                      |
|------------------------|----------|-----------------------------------|-------------------------------------------------------------------------------------------|
| `fromArray()`          | statyczna| `EsbCalculateBasicOfferRestReturn` | Tworzy wynik obliczenia z surowych danych API, parsując znacznik czasu i budując warianty. |
| `emptyForTransaction()`| statyczna| `EsbCalculateBasicOfferRestReturn` | Tworzy pusty wynik obliczenia dla danego identyfikatora transakcji, bez wariantów i z wyczyszczonymi flagami. |

`fromArray()` odczytuje `transactionId` i `calculationId`, parsuje `calculationTimestamp` do `\DateTimeImmutable`, gdy to możliwe, buduje tablicę `OfferVariant` z pola `variants` oraz interpretuje `basketCalculation` jako flagę logiczną.

`emptyForTransaction()` jest używane przez wysokopoziomowy [`EflClient`](../02.efl-client/01.overview.md), gdy punkt końcowy `/Calculation/CalculateBasicOffer` zwraca pomyślną odpowiedź z pustym ciałem, tworząc wynik z danym `transactionId`, pustą tablicą `variants` i `basketCalculation` ustawionym na `false`.

## Użycie w SDK

- Zwracane przez [`EflClient::calculateBasicOffer`](../02.efl-client/07.calculate-basic-offer.md).
- Osadzone wewnątrz [`CalculationData`](05.calculation-data.md) w polu `calculation`.
