## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Calculation\FinancialInsurance` modeluje komponent ubezpieczeniowy oferty.
Jest zagnieżdżony wewnątrz [`OfferFinancial`](09.offer-financial.md) oraz [`AssetOfferFinancial`](10.asset-offer-financial.md), oddzielając koszty ubezpieczenia od czystego finansowania.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Calculation`
- **Klasa**: final `FinancialInsurance`

```php
final class FinancialInsurance
{
    public ?float $netInsuranceInstallmentAmount;
    public ?float $vatInsuranceInstallmentAmount;
    public ?float $grossInsuranceInstallmentAmount;
    public ?float $netInsuranceTotalAmount;
    public ?float $grossInsuranceTotalAmount;

    public function __construct(
        ?float $netInsuranceInstallmentAmount,
        ?float $vatInsuranceInstallmentAmount,
        ?float $grossInsuranceInstallmentAmount,
        ?float $netInsuranceTotalAmount,
        ?float $grossInsuranceTotalAmount
    );

    public static function fromArray(array $data): self;
}
```

## Właściwości

| Nazwa                           | Typ         | Wymagane | Opis                                                     |
|---------------------------------|-------------|----------|----------------------------------------------------------|
| `netInsuranceInstallmentAmount` | `float\|null`| Nie      | Kwota ubezpieczenia netto na ratę.                       |
| `vatInsuranceInstallmentAmount`| `float\|null`| Nie      | Część VAT raty ubezpieczeniowej.                         |
| `grossInsuranceInstallmentAmount` | `float\|null` | Nie    | Kwota ubezpieczenia brutto na ratę.                      |
| `netInsuranceTotalAmount`      | `float\|null`| Nie      | Całkowita kwota ubezpieczenia netto.                     |
| `grossInsuranceTotalAmount`    | `float\|null`| Nie      | Całkowita kwota ubezpieczenia brutto.                    |

## Metody

| Metoda        | Rodzaj   | Typ zwracany          | Opis                                                                 |
|---------------|----------|----------------------|----------------------------------------------------------------------|
| `fromArray()` | statyczna| `FinancialInsurance` | Tworzy dane finansowe ubezpieczenia z surowej odpowiedzi API, rzutując pola numeryczne. |

`fromArray()` rzutuje pola numeryczne z odpowiedzi API.

## Użycie w SDK

- Używane jako `insurance` w [`OfferFinancial`](09.offer-financial.md) oraz [`AssetOfferFinancial`](10.asset-offer-financial.md).
- Pozwala aplikacjom na oddzielenie kosztów ubezpieczenia od innych komponentów finansowania podczas wyświetlania ofert.
