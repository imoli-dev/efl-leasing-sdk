## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Lead\StatementLead` modeluje oświadczenie lub zgodę powiązaną z leadem.
Jest częścią ładunku [`ContactData`](23.contact-data.md) dla `/Lead/SendContactForm`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Lead`
- **Klasa**: final `StatementLead`

```php
final class StatementLead
{
    public static function builder(): StatementLeadBuilder;

    public function __construct(
        int $statementConfigurationId,
        ?int $statementCategoryId = null,
        ?bool $selected = null
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa                      | Typ       | Wymagane | Opis                                                     |
|---------------------------|-----------|----------|----------------------------------------------------------|
| `statementConfigurationId`| `int`     | Tak      | Identyfikator konfiguracji oświadczenia.                 |
| `statementCategoryId`     | `int\|null`| Nie      | Opcjonalny identyfikator kategorii.                      |
| `selected`                | `bool\|null`| Nie      | Czy oświadczenie jest wybrane/zaakceptowane.             |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `StatementLeadBuilder` | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `StatementLead`. |
| `toRequestPayload()` | instancji| `array<string,mixed>` | Serializuje oświadczenie do struktury oczekiwanej przez EFL.         |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `statementConfigurationId` – mapuje się na właściwość,
- `statementCategoryId` – uwzględniany tylko wtedy, gdy nie jest równy null,
- `selected` – uwzględniany tylko wtedy, gdy nie jest równy null.

## Użycie w SDK

- Używany w tablicy `statementLeads` wewnątrz [`ContactData`](23.contact-data.md).
- Używany pośrednio przez [`EflClient::sendContactForm`](../02.efl-client/16.send-contact-form.md).
