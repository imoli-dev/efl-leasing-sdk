## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Model\Customer\CustomerData` reprezentuje główny ładunek danych klienta wysyłany do `/Customer/PostCustomerDataForLon`.
Wiąże identyfikator transakcji, identyfikator wybranej oferty oraz informacje o firmie wymagane przez EFL.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Model\Customer`
- **Klasa**: final `CustomerData`

```php
final class CustomerData
{
    public static function builder(string $transactionId, int $offerId): CustomerDataBuilder;

    public function __construct(
        string $transactionId,
        int $offerId,
        Company $company
    );

    public function toRequestPayload(): array;
}
```

## Właściwości

| Nazwa           | Typ       | Wymagane | Opis                                             |
|----------------|-----------|----------|--------------------------------------------------|
| `transactionId`| `string`  | Tak      | Identyfikator bieżącej transakcji.               |
| `offerId`      | `int`     | Tak      | Identyfikator wybranego wariantu oferty.         |
| `company`      | `Company` | Tak      | Dane firmy, w tym adresy, kontakty i oświadczenia. |

## Metody

| Metoda               | Rodzaj   | Typ zwracany          | Opis                                                                 |
|----------------------|----------|-----------------------|----------------------------------------------------------------------|
| `builder()`          | statyczna| `CustomerDataBuilder` | Zwraca płynnego budowniczego (fluent builder) do tworzenia instancji `CustomerData`. |
| `toRequestPayload()` | instancji| `array<string,mixed>`  | Serializuje dane klienta do struktury oczekiwanej przez API.         |

`toRequestPayload()` zwraca tablicę o następującym kształcie:

- `transactionId` – mapuje się na właściwość `transactionId`,
- `offerId` – mapuje się na właściwość `offerId`,
- `company` – zagnieżdżona struktura z `Company::toRequestPayload()`.

## Użycie w SDK

- Używane przez [`EflClient::submitCustomerData`](../02.efl-client/10.submit-customer-data.md).
- Przekazywane do `CustomerApiClient::postCustomerDataForLon()` jako ładunek żądania.
