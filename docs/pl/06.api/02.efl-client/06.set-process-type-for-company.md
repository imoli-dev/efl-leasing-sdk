---
title: setProcessTypeForCompany
description: Ustawia typ procesu dla firmy dla danej transakcji.
---

`setProcessTypeForCompany()` konfiguruje typ procesu dla firmy w kontekście danej transakcji.
Opakowuje `ProcessApiClient::setProcessTypeForCompany()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function setProcessTypeForCompany(
    string $transactionId,
    string $bearerToken,
    ?string $nip = null,
    ?bool $basketCalculation = null
): void
```

## Parametry

| Nazwa               | Typ                   | Wymagany | Opis                                                        |
| ------------------ | --------------------- | -------- | ----------------------------------------------------------- |
| `transactionId`    | `string`              | Tak      | Identyfikator transakcji.                                   |
| `bearerToken`      | `string`              | Tak      | Token Bearer.                                               |
| `nip`              | `string|null`        | Nie       | Opcjonalny numer identyfikacji podatkowej (NIP) firmy.     |
| `basketCalculation`| `bool|null`          | Nie       | Czy używana jest kalkulacja koszykowa.                      |

## Wartość zwracana

- **Typ**: `void` – użyj wyjątków i logowania, aby wykryć błędy.
