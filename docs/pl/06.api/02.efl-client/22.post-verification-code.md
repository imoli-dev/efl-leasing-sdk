`postVerificationCode()` przesyła kod weryfikacyjny dla transakcji.
Opakowuje `ProcessApiClient::postVerificationCode()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function postVerificationCode(
    PostVerificationCode $code,
    string $bearerToken
): void
```

## Parametry

| Nazwa         | Typ                                                          | Wymagany | Opis                                    |
| ------------ | ------------------------------------------------------------ | -------- | --------------------------------------- |
| `code`       | [`PostVerificationCode`](../04.models/43.post-verification-code.md) | Tak      | Ładunek kodu weryfikacyjnego.           |
| `bearerToken`| `string`                                                     | Tak      | Token Bearer.                           |

## Wartość zwracana

- **Typ**: `void` – niepowodzenia są zgłaszane poprzez wyjątki.
