description: Inicjuje weryfikację tożsamości poprzez BlueMedia i zwraca wynik inicjalizacji.

`initializeIdentityVerification()` rozpoczyna proces weryfikacji tożsamości dla transakcji przy użyciu BlueMedia.
Opakowuje `CustomerApiClient::initializeIdentityVerification()` i mapuje odpowiedź JSON na `VerificationInitializationResult`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function initializeIdentityVerification(
    string $transactionId,
    VerificationInitializationParams $params,
    string $bearerToken
): VerificationInitializationResult
```

## Parametry

| Nazwa           | Typ                                                                         | Wymagany | Opis                                                 |
| -------------- | ---------------------------------------------------------------------------- | -------- | ---------------------------------------------------- |
| `transactionId`| `string`                                                                     | Tak      | Identyfikator transakcji.                            |
| `params`       | [`VerificationInitializationParams`](../04.models/37.verification-initialization-params.md) | Tak      | Parametry opisujące konfigurację weryfikacji.        |
| `bearerToken`  | `string`                                                                     | Tak      | Token Bearer.                                        |

## Wartość zwracana

- **Typ**: [`VerificationInitializationResult`](../04.models/38.verification-initialization-result.md) – wynik inicjalizacji z adresem URL przekierowania i identyfikatorami.
