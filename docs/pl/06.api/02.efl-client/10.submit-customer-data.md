`submitCustomerData()` wysyła dane klienta (firmy lub osoby) do API EFL dla bieżącej transakcji.
Opakowuje `CustomerApiClient::postCustomerDataForLon()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function submitCustomerData(CustomerData $customerData, string $bearerToken): void
```

## Parametry

| Nazwa           | Typ                                             | Wymagany | Opis                                            |
| -------------- | ----------------------------------------------- | -------- | ----------------------------------------------- |
| `customerData` | [`CustomerData`](../04.models/15.customer-data.md) | Tak      | Kompletny ładunek danych klienta.               |
| `bearerToken`  | `string`                                        | Tak      | Token Bearer.                                   |

## Wartość zwracana

- **Typ**: `void` – niepowodzenia są zgłaszane poprzez wyjątki.
