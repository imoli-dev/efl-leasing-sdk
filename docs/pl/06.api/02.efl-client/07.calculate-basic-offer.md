`calculateBasicOffer()` wysyła żądanie kalkulacji dla koszyka przedmiotów i zwraca typowany model `EsbCalculateBasicOfferRestReturn`.
Wewnętrznie opakowuje `CalculationApiClient::calculateBasicOffer()` i dekoduje odpowiedź JSON.
Gdy API zwróci pustą treść lub brak wariantów, SDK próbuje pobrać wynik kalkulacji za pomocą `getBaseData()`.
Jeśli oba źródła nie zwrócą żadnych wariantów, SDK zwraca instancję [`EsbCalculateBasicOfferRestReturn`](../04.models/06.esb-calculate-basic-offer-rest-return.md) utworzoną za pomocą `emptyForTransaction()`, z podanym identyfikatorem transakcji i pustą listą wariantów.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function calculateBasicOffer(
    AssetToCalculation $basket,
    string $bearerToken
): EsbCalculateBasicOfferRestReturn
```

## Parametry

| Nazwa         | Typ                                                    | Wymagany | Opis                                            |
| ------------ | ------------------------------------------------------ | -------- | ----------------------------------------------- |
| `basket`     | [`AssetToCalculation`](../04.models/02.asset-to-calculation.md) | Tak      | Koszyk przedmiotów, dla których ma zostać obliczona oferta. |
| `bearerToken`| `string`                                               | Tak      | Token Bearer używany do uwierzytelnionego wywołania kalkulacji. |

## Wartość zwracana

- **Typ**: [`EsbCalculateBasicOfferRestReturn`](../04.models/06.esb-calculate-basic-offer-rest-return.md) – typowany wynik z wariantami oferty i szczegółami finansowymi.
