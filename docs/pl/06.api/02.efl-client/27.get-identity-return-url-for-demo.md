`getIdentityReturnUrlForDemo()` pobiera adres URL powrotu weryfikacji tożsamości z API demo.
Opakowuje `DemoApiClient::getIdentityReturnUrl()` i zwraca surowy ciąg znaków URL.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getIdentityReturnUrlForDemo(): string
```

## Parametry

Ta metoda nie przyjmuje żadnych parametrów.

## Wartość zwracana

- **Typ**: `string` – adres URL powrotu weryfikacji tożsamości dla scenariuszy demo.
