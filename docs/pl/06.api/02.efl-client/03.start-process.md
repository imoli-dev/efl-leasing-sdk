---

`startProcess()` inicjuje proces leasingowy dla danego partnera i adresów URL powrotnych.
Opakowuje niskopoziomowy punkt końcowy `ProcessApiClient::init()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function startProcess(
    ?string $positiveUrlResponse,
    ?string $negativeUrlResponse,
    string $bearerToken
): string
```

## Parametry

| Nazwa                 | Typ                  | Wymagany | Opis                                                                   |
| -------------------- | -------------------- | -------- | ---------------------------------------------------------------------- |
| `positiveUrlResponse`| `string|null`       | Nie       | URL używany, gdy proces zakończy się sukcesem; może być `null`.        |
| `negativeUrlResponse`| `string|null`       | Nie       | URL używany, gdy proces zakończy się niepowodzeniem lub zostanie anulowany; może być `null`. |
| `bearerToken`        | `string`             | Tak      | Token Bearer uzyskany za pomocą [`getAuthToken`](02.get-auth-token.md). |

## Wartość zwracana

- **Typ**: `string` – surowa treść odpowiedzi, zazwyczaj zawierająca adres URL przekierowania lub identyfikator procesu.
