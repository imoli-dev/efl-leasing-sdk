---
title: getProcessChanges
description: Zwraca zmiany procesu dla danej transakcji z opcjonalnymi filtrami statusu BPM.
---

`getProcessChanges()` pobiera bieżący stan procesu i historię zmian dla transakcji.
Wewnętrznie mapuje surową odpowiedź HTTP z `ProcessApiClient::getChanges()` na model `FoicProcessStateResponse`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getProcessChanges(
    string $transactionId,
    ?array $statusBpm,
    string $bearerToken
): FoicProcessStateResponse
```

## Parametry

| Nazwa           | Typ                     | Wymagany | Opis                                                                     |
| -------------- | ----------------------- | -------- | ------------------------------------------------------------------------ |
| `transactionId`| `string`                | Tak      | Identyfikator transakcji, której zmiany procesu chcesz sprawdzić.       |
| `statusBpm`    | `string[]|null`        | Nie       | Opcjonalna lista kodów statusu BPM do filtrowania; `null` oznacza brak filtra. |
| `bearerToken`  | `string`                | Tak      | Token Bearer.                                                            |

## Wartość zwracana

- **Typ**: [`FoicProcessStateResponse`](../04.models/27.foic-process-state-response.md) – typowana informacja o stanie procesu.
