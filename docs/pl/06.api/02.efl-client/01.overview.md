## Cel

`EflClient` jest głównym punktem wejścia dla większości integracji.
Orkiestruje wywołania do bazowych [klientów API](../03.clients/02.process-api-client.md) i udostępnia metody wysokiego poziomu, które odpowiadają typowym scenariuszom ecommerce, takim jak:

- Rozpoczęcie procesu leasingowego dla zamówienia.
- Obliczanie podstawowych ofert dla koszyka przedmiotów.
- Przesyłanie danych klienta i oświadczeń.
- Inicjowanie weryfikacji tożsamości i sprawdzanie jej statusu.
- Wysyłanie leadów i formularzy kontaktowych.

Wewnętrznie używa klientów niskiego poziomu z przestrzeni nazw `Api` i konwertuje dane między modelami zdefiniowanymi w przestrzeni nazw [`Model`](../04.models/01.overview.md).

## Konstrukcja

Zazwyczaj tworzysz instancję `EflClient` raz i używasz jej wielokrotnie:

```php
use GuzzleHttp\Client as GuzzleClient;
use Imoli\EflLeasingSdk\Config;
use Imoli\EflLeasingSdk\EflClient;
use Imoli\EflLeasingSdk\Http\Adapter\GuzzleHttpAdapter;

$config = Config::sandbox(
    apiKey: 'your-sandbox-api-key',
    baseUrl: 'https://leasingonlineapi-sandbox.efl.com.pl'
);

$guzzle = new GuzzleClient([
    'timeout' => 30,
    'connect_timeout' => 10,
]);

$httpClient = new GuzzleHttpAdapter($guzzle);

$client = new EflClient($config, $httpClient);
```

## Typowy wzorzec użycia

Typowy proces z użyciem `EflClient` wygląda następująco:

1. Pobranie tokena uwierzytelniającego.
2. Rozpoczęcie procesu leasingowego.
3. Obliczenie ofert dla koszyka.
4. Przeslanie danych klienta i oświadczeń.
5. Przeprowadzenie weryfikacji tożsamości i kroków pay‑by‑link.
6. Opcjonalne wysłanie leadów lub przywrócenie procesów.

Metody wysokiego poziomu są zaprojektowane do użycia w kodzie kontrolerów lub serwisów Twojej aplikacji, izolując logikę SDK od reszty logiki biznesowej.
