---
title: getSectorClassAndType
description: Zwraca informacje o sektorze, klasie i typie produktu dla danej transakcji.
---

`getSectorClassAndType()` pobiera informacje o sektorze, klasie i typie produktu w kontekście transakcji.
Opakowuje `ProductsApiClient::getSectorClassAndType()` i mapuje odpowiedź na `SectorProductInfoTree`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getSectorClassAndType(
    string $transactionId,
    string $bearerToken
): SectorProductInfoTree
```

## Parametry

| Nazwa           | Typ      | Wymagany | Opis                             |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |
| `bearerToken`  | `string` | Tak      | Token Bearer.                  |

## Wartość zwracana

- **Typ**: [`SectorProductInfoTree`](../04.models/33.sector-product-info-tree.md) – drzewo informacji o sektorze, klasie i typie.
