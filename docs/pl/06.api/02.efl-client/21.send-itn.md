`sendItn()` wysyła ładunek ITN do punktu końcowego testowania w piaskownicy.
Opakowuje `TestingApiClient::sendItn()` i jest zazwyczaj używany tylko w środowiskach nieprodukcyjnych.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function sendItn(array $transactionListFlattened, string $bearerToken): void
```

## Parametry

| Nazwa                      | Typ                   | Wymagany | Opis                                                         |
| ------------------------- | ---------------------- | -------- | ------------------------------------------------------------ |
| `transactionListFlattened`| `array<string, mixed>` | Tak      | Tablica asocjacyjna ze spłaszczonym ładunkiem listy transakcji. |
| `bearerToken`             | `string`               | Tak      | Token Bearer dla punktu końcowego testowania w piaskownicy. |

## Wartość zwracana

- **Typ**: `void` – niepowodzenia są zgłaszane poprzez wyjątki.
