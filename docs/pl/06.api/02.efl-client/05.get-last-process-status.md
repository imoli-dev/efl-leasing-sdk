---
title: getLastProcessStatus
description: Zwraca ostatni status procesu jako ciąg znaków dla danej transakcji.
---

`getLastProcessStatus()` zapewnia wygodny sposób na odczytanie najnowszego statusu procesu leasingowego.
Opakowuje `ProcessApiClient::getLastStatus()` i zwraca status jako zwykły ciąg znaków.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getLastProcessStatus(string $transactionId, string $bearerToken): string
```

## Parametry

| Nazwa           | Typ      | Wymagany | Opis                             |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |
| `bearerToken`  | `string` | Tak      | Token Bearer.                  |

## Wartość zwracana

- **Typ**: `string` – surowy ciąg znaków statusu zwrócony przez API.
