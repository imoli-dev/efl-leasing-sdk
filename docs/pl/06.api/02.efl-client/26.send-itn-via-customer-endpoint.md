title: sendItnViaCustomerEndpoint
description: Wysyła ładunek ITN poprzez punkt końcowy Customer ITN.
---

`sendItnViaCustomerEndpoint()` wysyła ładunek ITN przy użyciu punktu końcowego `/Customer/ITN` zamiast punktu końcowego testowania.
Opakowuje `CustomerApiClient::postItn()` i jest zazwyczaj używany w bardziej realistycznych scenariuszach integracji.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function sendItnViaCustomerEndpoint(string $transactionsPayload): void
```

## Parametry

| Nazwa                | Typ      | Wymagany | Opis                                             |
| ------------------- | -------- | -------- | ------------------------------------------------ |
| `transactionsPayload` | `string` | Tak      | Surowy ładunek transakcji, zazwyczaj XML.        |

## Wartość zwracana

- **Typ**: `void` – niepowodzenia są zgłaszane poprzez wyjątki.
