`getAuthToken()` jest punktem wejścia do uzyskania tokena Bearer, który będzie używany w kolejnych wywołaniach do API EFL Leasing Online.
Opakowuje niskopoziomowe wywołanie `ProcessApiClient::getToken()` i zwraca token jako zwykły ciąg znaków.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

Obsłuż te wyjątki na granicy swojej aplikacji.

## Sygnatura metody

```php
public function getAuthToken(string $partnerId): string
```

## Parametry

| Nazwa      | Typ      | Wymagany | Opis                                   |
| ---------- | -------- | -------- | -------------------------------------- |
| `partnerId`| `string` | Tak      | Identyfikator partnera przypisany przez EFL. |

## Wartość zwracana

- **Typ**: `string` – ciąg znaków tokena, który ma być użyty jako token Bearer w kolejnych wywołaniach API.
