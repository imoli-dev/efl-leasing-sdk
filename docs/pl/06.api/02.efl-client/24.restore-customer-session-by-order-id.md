`restoreCustomerSessionByOrderId()` przywraca sesję klienta przy użyciu identyfikatora zamówienia pay‑by‑link.
Opakowuje `RestorationApiClient::restoreCustomerSession()` i mapuje odpowiedź na `AuthenticationRestorationResult`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function restoreCustomerSessionByOrderId(
    string $payByLinkOrderId
): AuthenticationRestorationResult
```

## Parametry

| Nazwa              | Typ      | Wymagany | Opis                                         |
| ----------------- | -------- | -------- | -------------------------------------------- |
| `payByLinkOrderId`| `string` | Tak      | Identyfikator zamówienia użyty w pay‑by‑link.|

## Wartość zwracana

- **Typ**: [`AuthenticationRestorationResult`](../04.models/35.authentication-restoration-result.md) – wynik przywracania.
