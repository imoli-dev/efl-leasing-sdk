---
title: initiatePayByLinkPayment
description: Inicjuje płatność pay-by-link dla danej transakcji.
---

`initiatePayByLinkPayment()` uruchamia płatność pay-by-link dla transakcji i zwraca surową treść odpowiedzi.
Opakowuje `CustomerApiClient::postInitiatePayByLinkPayment()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function initiatePayByLinkPayment(
    string $transactionId,
    string $bearerToken
): string
```

## Parametry

| Nazwa           | Typ      | Wymagany | Opis                             |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |
| `bearerToken`  | `string` | Tak      | Token Bearer.                  |

## Wartość zwracana

- **Typ**: `string` – surowa treść odpowiedzi zwrócona przez API (zawartość zależy od specyfikacji EFL).
