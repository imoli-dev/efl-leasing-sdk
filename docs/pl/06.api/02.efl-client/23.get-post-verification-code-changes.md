---
title: getPostVerificationCodeChanges
description: Zwraca zmiany procesu po weryfikacji kodu dla danej transakcji.
---

`getPostVerificationCodeChanges()` pobiera surowe informacje o zmianach po przesłaniu kodu weryfikacyjnego.
Opakowuje `ProcessApiClient::getPostVerificationCodeChanges()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getPostVerificationCodeChanges(
    string $transactionId,
    string $bearerToken
): string
```

## Parametry

| Nazwa           | Typ      | Wymagany | Opis                             |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |
| `bearerToken`  | `string` | Tak      | Token Bearer.                  |

## Wartość zwracana

- **Typ**: `string` – surowa treść odpowiedzi opisująca zmiany po weryfikacji kodu.
