`submitLeadVerificationResult()` wysyła wynik weryfikacji leada z powrotem do API EFL.
Opakowuje `CustomerApiClient::leadVerificationResult()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function submitLeadVerificationResult(
    string $transactionId,
    VerificationResult $result,
    string $bearerToken
): void
```

## Parametry

| Nazwa           | Typ                                                          | Wymagany | Opis                                         |
| -------------- | ------------------------------------------------------------- | -------- | -------------------------------------------- |
| `transactionId`| `string`                                                      | Tak      | Identyfikator transakcji.                    |
| `result`       | [`VerificationResult`](../04.models/39.verification-result.md) | Tak      | Dane wyniku weryfikacji do przesłania.       |
| `bearerToken`  | `string`                                                      | Tak      | Token Bearer.                                |

## Wartość zwracana

- **Typ**: `void` – niepowodzenia są zgłaszane poprzez wyjątki.
