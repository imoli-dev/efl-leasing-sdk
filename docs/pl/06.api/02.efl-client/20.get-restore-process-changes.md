---
title: getRestoreProcessChanges
description: Zwraca zmiany procesu przywracania dla danej transakcji.
---

`getRestoreProcessChanges()` zwraca surowe informacje o zmianach dla procesu przywracania.
Opakowuje `ProcessApiClient::getRestoreProcessChanges()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getRestoreProcessChanges(string $transactionId): string
```

## Parametry

| Nazwa           | Typ      | Wymagany | Opis                             |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |

## Wartość zwracana

- **Typ**: `string` – surowa treść odpowiedzi opisująca zmiany w procesie przywracania.
