---
title: acceptCalculation
description: Akceptuje wcześniej obliczoną ofertę dla danej transakcji.
---

`acceptCalculation()` potwierdza wybraną kalkulację i wariant dla transakcji.
Opakowuje `CalculationApiClient::acceptCalculation()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function acceptCalculation(
    string $transactionId,
    int $calculationId,
    int $calculationVariantId,
    ?bool $basketCalculation,
    string $bearerToken
): void
```

## Parametry

| Nazwa               | Typ                | Wymagany | Opis                                                        |
| ------------------ | ------------------ | -------- | ----------------------------------------------------------- |
| `transactionId`    | `string`           | Tak      | Identyfikator transakcji.                                   |
| `calculationId`    | `int`              | Tak      | Identyfikator kalkulacji do zaakceptowania.                 |
| `calculationVariantId` | `int`          | Tak      | Identyfikator wariantu kalkulacji do zaakceptowania.        |
| `basketCalculation`| `bool|null`       | Nie       | Czy używana jest kalkulacja koszykowa.                      |
| `bearerToken`      | `string`           | Tak      | Token Bearer.                                               |

## Wartość zwracana

- **Typ**: `void` – błędy są zgłaszane poprzez wyjątki.
