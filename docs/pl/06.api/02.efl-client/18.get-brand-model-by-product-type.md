description: Zwraca informacje o marce i modelu dla danego typu produktu w kontekście transakcji.
---

`getBrandModelByProductType()` pobiera informacje o marce i modelu dla wybranego typu produktu i transakcji.
Opakowuje `ProductsApiClient::getBrandModelByProductTypeIdAndPartnerGuid()` i mapuje odpowiedź na `BrandProductInfoTree`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getBrandModelByProductType(
    string $transactionId,
    int $productTypeId,
    string $bearerToken
): BrandProductInfoTree
```

## Parametry

| Nazwa           | Typ      | Wymagany | Opis                                 |
| -------------- | -------- | -------- | ----------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.           |
| `productTypeId`| `int`    | Tak      | Identyfikator typu produktu.        |
| `bearerToken`  | `string` | Tak      | Token Bearer.                      |

## Wartość zwracana

- **Typ**: [`BrandProductInfoTree`](../04.models/34.brand-product-info-tree.md) – drzewo marek i modeli dla danego typu produktu.
