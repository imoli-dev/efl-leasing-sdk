---
title: getIdentityVerificationStatus
description: Zwraca bieżący status weryfikacji tożsamości dla danej transakcji.
---

`getIdentityVerificationStatus()` odpytuje o status weryfikacji tożsamości dla transakcji.
Opakowuje `CustomerApiClient::getIdentityVerificationStatus()` i mapuje odpowiedź na `BlueMediaProcessStateResponse`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getIdentityVerificationStatus(
    string $transactionId,
    string $bearerToken
): BlueMediaProcessStateResponse
```

## Parametry

| Nazwa           | Typ      | Wymagany | Opis                             |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |
| `bearerToken`  | `string` | Tak      | Token Bearer.                  |

## Wartość zwracana

- **Typ**: [`BlueMediaProcessStateResponse`](../04.models/40.blue-media-process-state-response.md) – bieżący status weryfikacji.
