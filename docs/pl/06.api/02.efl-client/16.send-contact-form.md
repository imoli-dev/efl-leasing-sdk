`sendContactForm()` przesyła informacje kontaktowe/lead do API EFL.
Opakowuje `LeadApiClient::sendContactForm()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function sendContactForm(
    string $transactionId,
    ContactData $contactData,
    string $bearerToken
): void
```

## Parametry

| Nazwa           | Typ                                              | Wymagany | Opis                                                  |
| -------------- | ------------------------------------------------ | -------- | ----------------------------------------------------- |
| `transactionId`| `string`                                         | Tak      | Identyfikator transakcji powiązanej z leadem.         |
| `contactData`  | [`ContactData`](../04.models/23.contact-data.md) | Tak      | Ładunek danych leada/kontaktowych.                    |
| `bearerToken`  | `string`                                         | Tak      | Token Bearer.                                         |

## Wartość zwracana

- **Typ**: `void` – niepowodzenia są zgłaszane poprzez wyjątki.
