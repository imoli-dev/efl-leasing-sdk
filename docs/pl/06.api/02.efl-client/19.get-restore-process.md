`getRestoreProcess()` pobiera dane przywracania procesu (partnera i token) dla transakcji.
Opakowuje `ProcessApiClient::getRestoreProcess()` i mapuje odpowiedź na `AuthenticateResponse`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getRestoreProcess(string $transactionId): AuthenticateResponse
```

## Parametry

| Nazwa           | Typ      | Wymagany | Opis                             |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |

## Wartość zwracana

- **Typ**: [`AuthenticateResponse`](../04.models/26.authenticate-response.md) – dane przywracania procesu (partner i token).
