`getBaseData()` pobiera dane podstawowe kalkulacji dla transakcji i mapuje odpowiedź JSON na model `CalculationData`.
Opakowuje `CalculationApiClient::getBaseData()`.

Wszystkie metody w [`EflClient`](01.overview.md) mogą zgłaszać:

- [`ApiException`](../06.errors.md#apiexception-and-problemdetails) – gdy API EFL zwróci odpowiedź z błędem.
- [`HttpException`](../06.errors.md#httpexception) – gdy transport HTTP zawiedzie.

## Sygnatura metody

```php
public function getBaseData(string $transactionId, string $bearerToken): CalculationData
```

## Parametry

| Nazwa           | Typ      | Wymagany | Opis                             |
| -------------- | -------- | -------- | ------------------------------- |
| `transactionId`| `string` | Tak      | Identyfikator transakcji.       |
| `bearerToken`  | `string` | Tak      | Token Bearer.                  |

## Wartość zwracana

- **Typ**: [`CalculationData`](../04.models/05.calculation-data.md) – struktura danych podstawowych używana w kalkulacjach.
