## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\CustomerDataBuilder` to pomocnik typu fluent do budowania instancji `CustomerData`.
Jest on zazwyczaj używany przed wywołaniem `/Customer/PostCustomerDataForLon` za pośrednictwem `EflClient::submitCustomerData()`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `CustomerDataBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Customer\CustomerData`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Customer\Company;
use Imoli\EflLeasingSdk\Model\Customer\CustomerData;

final class CustomerDataBuilder
{
    public function __construct(string $transactionId, int $offerId);

    public function withCompany(Company $company): self;

    public function build(): CustomerData;
}
```

## Fluent API

- **__construct(string $transactionId, int $offerId)**  
  Inicjalizuje builder z wymaganymi `transactionId` i `offerId` pochodzącymi z kalkulacji oferty.

- **withCompany(Company $company): self**  
  Ustawia dane klienta na poziomie firmy powiązane z tą transakcją.

- **build(): CustomerData**  
  - Wymaga ustawienia `company`.  
  - Rzuca `\LogicException`, jeśli brakuje `company`.  
  - Zwraca nową instancję `CustomerData` gotową do serializacji i wysłania do API.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\CustomerDataBuilder;

// $company to model Company, np. zbudowany za pomocą CompanyBuilder
$customerData = (new CustomerDataBuilder('tx-1', 1234))
    ->withCompany($company)
    ->build();
```
