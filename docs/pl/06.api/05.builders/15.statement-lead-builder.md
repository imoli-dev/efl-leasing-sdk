## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\StatementLeadBuilder` to pomocnik typu fluent do budowania instancji `StatementLead`.
Reprezentuje on pojedyncze oświadczenie/zgodę powiązaną z leadem w formularzach kontaktowych.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `StatementLeadBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Lead\StatementLead`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Lead\StatementLead;

final class StatementLeadBuilder
{
    public function withStatementConfigurationId(int $statementConfigurationId): self;
    public function withStatementCategoryId(?int $statementCategoryId): self;
    public function withSelected(?bool $selected): self;

    public function build(): StatementLead;

    public static function create(int $statementConfigurationId): self;
}
```

## Fluent API

- **withStatementConfigurationId(int $statementConfigurationId): self**  
  Ustawia identyfikator konfiguracji oświadczenia (wymagane).

- **withStatementCategoryId(?int $statementCategoryId): self**  
  Opcjonalnie ustawia identyfikator kategorii dla oświadczenia.

- **withSelected(?bool $selected): self**  
  Opcjonalnie oznacza oświadczenie jako wybrane/zaakceptowane (`true`), odrzucone (`false`) lub nieokreślone (`null`).

- **build(): StatementLead**  
  - Wymaga ustawienia `statementConfigurationId`.  
  - Rzuca `\LogicException`, jeśli go brakuje.  
  - Zwraca nową instancję `StatementLead`.

- **static create(int $statementConfigurationId): self**  
  Wygodna fabryka, która ustawia wymagany identyfikator konfiguracji.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\StatementLeadBuilder;

$statementLead = StatementLeadBuilder::create(1001)
    ->withSelected(true)
    ->build();
```
