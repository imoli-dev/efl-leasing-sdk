## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\ProspectBuilder` to pomocnik typu fluent do budowania instancji `Prospect`.
Reprezentuje on podstawowe dane leada, takie jak imię, nazwisko, identyfikator podatkowy, lokalizacja i informacje kontaktowe.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `ProspectBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Lead\Prospect`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Lead\Prospect;

final class ProspectBuilder
{
    public function withFirstName(string $firstName): self;
    public function withLastName(string $lastName): self;
    public function withNip(string $nip): self;
    public function withPostal(string $postal): self;
    public function withPhoneNo(string $phoneNo): self;
    public function withEmail(string $email): self;
    public function withDescription(?string $description): self;

    public function build(): Prospect;

    public static function create(
        string $firstName,
        string $lastName,
        string $nip,
        string $postal,
        string $phoneNo,
        string $email
    ): self;
}
```

## Fluent API

- **withFirstName/withLastName(string $...): self** – ustawiają imię i nazwisko osoby kontaktowej leada.  
- **withNip(string $nip): self** – ustawia identyfikator podatkowy (NIP).  
- **withPostal(string $postal): self** – ustawia kod pocztowy lub ciąg znaków lokalizacji.  
- **withPhoneNo(string $phoneNo): self** – ustawia numer telefonu.  
- **withEmail(string $email): self** – ustawia adres e-mail.  
- **withDescription(?string $description): self** – opcjonalnie ustawia opis lub notatkę w formie wolnego tekstu.

- **build(): Prospect**  
  - Wymaga: `firstName`, `lastName`, `nip`, `postal`, `phoneNo`, `email`.  
  - Rzuca `\LogicException`, jeśli któregokolwiek z nich brakuje.  
  - Zwraca nową instancję `Prospect`.

- **static create(...): self**  
  Wygodna fabryka, która ustawia wszystkie wymagane pola w jednym wywołaniu.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\ProspectBuilder;

$prospect = ProspectBuilder::create(
        'Jan',
        'Kowalski',
        '1234567890',
        '50-000 Wrocław',
        '+48 123456789',
        'jan.kowalski@example.com'
    )
    ->withDescription('Zainteresowany ofertą leasingu demo')
    ->build();
```
