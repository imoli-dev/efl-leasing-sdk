## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\PostVerificationCodeBuilder` to pomocnik typu fluent do budowania instancji `PostVerificationCode`.
Jest on używany podczas przesyłania kodu weryfikacyjnego z powrotem do API EFL za pośrednictwem `/Process/PostVerificationCode`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `PostVerificationCodeBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Verification\PostVerificationCode`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Verification\PostVerificationCode;

final class PostVerificationCodeBuilder
{
    public function withTransactionId(string $transactionId): self;
    public function withVerificationCode(string $verificationCode): self;

    public function build(): PostVerificationCode;

    public static function create(string $transactionId, string $verificationCode): self;
}
```

## Fluent API

- **withTransactionId(string $transactionId): self**  
  Ustawia identyfikator transakcji powiązany z próbą weryfikacji.

- **withVerificationCode(string $verificationCode): self**  
  Ustawia kod weryfikacyjny otrzymany od użytkownika lub systemu zewnętrznego.

- **build(): PostVerificationCode**  
  - Wymaga zarówno `transactionId`, jak i `verificationCode`.  
  - Rzuca `\LogicException`, jeśli któregokolwiek z nich brakuje.  
  - Zwraca nową instancję `PostVerificationCode`.

- **static create(string $transactionId, string $verificationCode): self**  
  Wygodna fabryka, która ustawia oba wymagane pola w jednym wywołaniu.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\PostVerificationCodeBuilder;

$payload = PostVerificationCodeBuilder::create('tx-1', '123456')
    ->build();
```
