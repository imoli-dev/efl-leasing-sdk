## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\CustomerDataStatementBuilder` to pomocnik typu fluent do budowania instancji `CustomerDataStatement`.
Reprezentuje on pojedyncze oświadczenie/zgodę klienta dołączoną do danych klienta.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `CustomerDataStatementBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Customer\CustomerDataStatement`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Customer\CustomerDataStatement;

final class CustomerDataStatementBuilder
{
    public function withGuid(string $guid): self;
    public function withAgreement(bool $agreement): self;
    public function withStatementTypeId(string $statementTypeId): self;
    public function withValidFrom(?string $validFrom): self;

    public function build(): CustomerDataStatement;

    public static function create(string $guid, bool $agreement, string $statementTypeId): self;
}
```

## Fluent API

- **withGuid(string $guid): self** – ustawia GUID oświadczenia.  
- **withAgreement(bool $agreement): self** – ustawia, czy oświadczenie zostało zaakceptowane.  
- **withStatementTypeId(string $statementTypeId): self** – ustawia identyfikator typu oświadczenia.  
- **withValidFrom(?string $validFrom): self** – opcjonalnie ustawia datę rozpoczęcia obowiązywania.

- **build(): CustomerDataStatement**  
  - Wymaga: `guid`, `agreement`, `statementTypeId`.  
  - Rzuca `\LogicException`, jeśli któregokolwiek z nich brakuje.  
  - Zwraca nową instancję `CustomerDataStatement`.

- **static create(string $guid, bool $agreement, string $statementTypeId): self**  
  Wygodna fabryka, która ustawia wymagane pola i zwraca builder gotowy na opcjonalne `validFrom`.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\CustomerDataStatementBuilder;

$statement = CustomerDataStatementBuilder::create('stmt-guid', true, 'RODO')
    ->withValidFrom('2024-01-01')
    ->build();
```
