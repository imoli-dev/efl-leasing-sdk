## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\PhoneBuilder` to pomocnik typu fluent do budowania instancji `Phone`.
Jest on używany wewnątrz `Company` i `Person` do reprezentowania numerów telefonów wraz z prefiksem, typem i rodzajem.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `PhoneBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Customer\Phone`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Customer\Phone;

final class PhoneBuilder
{
    public function withGuid(string $guid): self;
    public function withPrefix(string $prefix): self;
    public function withNumber(string $number): self;
    public function withTypeId(string $typeId): self;
    public function withKindId(string $kindId): self;

    public function build(): Phone;

    public static function create(
        string $guid,
        string $prefix,
        string $number,
        string $typeId,
        string $kindId
    ): self;
}
```

## Fluent API

- **withGuid(string $guid): self** – ustawia identyfikator wpisu telefonu.  
- **withPrefix(string $prefix): self** – ustawia prefiks telefonu (np. kod kraju/kierunkowy).  
- **withNumber(string $number): self** – ustawia numer telefonu.  
- **withTypeId(string $typeId): self** – ustawia typ telefonu (np. komórkowy, stacjonarny).  
- **withKindId(string $kindId): self** – ustawia rodzaj telefonu (służbowy, prywatny itp.).

- **build(): Phone**  
  - Wymaga: `guid`, `prefix`, `number`, `typeId`, `kindId`.  
  - Rzuca `\LogicException`, jeśli któregokolwiek z nich brakuje.  
  - Zwraca nową instancję `Phone`.

- **static create(...): self**  
  Wygodna fabryka, która ustawia wszystkie wymagane pola w jednym wywołaniu.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\PhoneBuilder;

$phone = PhoneBuilder::create('phone-guid', '+48', '123456789', 'MOBILE', 'BUSINESS')
    ->build();
```
