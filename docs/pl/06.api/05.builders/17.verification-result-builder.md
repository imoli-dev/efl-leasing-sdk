## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\VerificationResultBuilder` to pomocnik typu fluent do budowania instancji `VerificationResult`.
Reprezentuje on status i wynik weryfikacji tożsamości, który zostanie przesłany z powrotem do API EFL.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `VerificationResultBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Verification\VerificationResult`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Verification\VerificationResult;

final class VerificationResultBuilder
{
    public function withStatus(?string $status): self;
    public function withResult(?string $result): self;

    public function build(): VerificationResult;

    public static function create(): self;
}
```

## Fluent API

- **withStatus(?string $status): self**  
  Opcjonalnie ustawia kod/wartość statusu weryfikacji.

- **withResult(?string $result): self**  
  Opcjonalnie ustawia kod lub opis wyniku weryfikacji.

- **build(): VerificationResult**  
  - Nie wymusza żadnych wymaganych pól – zarówno `status`, jak i `result` są opcjonalne.  
  - Zwraca nową instancję `VerificationResult` ze skonfigurowanymi wartościami.

- **static create(): self**  
  Wygodna fabryka, która zwraca pusty builder.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\VerificationResultBuilder;

$verificationResult = VerificationResultBuilder::create()
    ->withStatus('OK')
    ->withResult('POSITIVE')
    ->build();
```
