## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\ContactDataBuilder` to pomocnik typu fluent do budowania instancji `ContactData`.
Jest on używany z `/Lead/SendContactForm` za pośrednictwem `EflClient::sendContactForm()` oraz `LeadApiClient::sendContactForm()`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `ContactDataBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Lead\ContactData`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Lead\ContactData;
use Imoli\EflLeasingSdk\Model\Lead\Prospect;
use Imoli\EflLeasingSdk\Model\Lead\StatementLead;

final class ContactDataBuilder
{
    public function withProspect(Prospect $prospect): self;

    public function addStatementLead(StatementLead $statementLead): self;

    public function build(): ContactData;
}
```

## Fluent API

- **withProspect(Prospect $prospect): self**  
  Ustawia szczegóły potencjalnego klienta (imię, nazwisko, NIP, dane kontaktowe).

- **addStatementLead(StatementLead $statementLead): self**  
  Dodaje wpis zgody `StatementLead` do listy `statementLeads`.

- **build(): ContactData**  
  - Wymaga ustawienia `prospect`.  
  - Rzuca `\LogicException`, jeśli brakuje `prospect`.  
  - Zwraca nową instancję `ContactData` z zebranymi zgódami `statementLeads`.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\ContactDataBuilder;

$contactData = (new ContactDataBuilder())
    ->withProspect($prospect)
    ->addStatementLead($statementLead)
    ->build();
```
