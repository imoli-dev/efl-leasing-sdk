## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\ItemDetailBuilder` to mały pomocnik typu fluent do budowania instancji `ItemDetail`.
`ItemDetail` reprezentuje pojedynczą parę klucz-wartość metadanych powiązanych z `OfferItem`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `ItemDetailBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Calculation\ItemDetail`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Calculation\ItemDetail;

final class ItemDetailBuilder
{
    public function withId(string $id): self;

    public function withValue(string $value): self;

    public function build(): ItemDetail;

    public static function create(string $id, string $value): self;
}
```

## Fluent API

- **withId(string $id): self**  
  Ustawia identyfikator szczegółu (np. kod z API EFL lub Twojego systemu).

- **withValue(string $value): self**  
  Ustawia tekstową wartość szczegółu.

- **build(): ItemDetail**  
  - Wymaga zarówno `id`, jak i `value`.  
  - Rzuca `\LogicException`, jeśli któregokolwiek z nich brakuje.  
  - Zwraca nową instancję `ItemDetail`.

- **static create(string $id, string $value): self**  
  Wygodna fabryka, która ustawia zarówno `id`, jak i `value` w jednym wywołaniu.

## Przykłady użycia

```php
use Imoli\EflLeasingSdk\Builder\ItemDetailBuilder;

$detail = ItemDetailBuilder::create('asset-code', 'Laptop X')->build();
```

W połączeniu z `OfferItemBuilder`:

```php
use Imoli\EflLeasingSdk\Builder\OfferItemBuilder;

$offerItem = OfferItemBuilder::create(1, 'asset-guid-1', 23.0, [$detail])
    ->build();
```
