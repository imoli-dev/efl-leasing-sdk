## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\AddressBuilder` to pomocnik typu fluent do budowania instancji `Address`.
Jest on używany wewnątrz modeli `Company` i `Person` do opisu adresów pocztowych, takich jak siedziba firmy lub adres do korespondencji.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `AddressBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Customer\Address`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Customer\Address;

final class AddressBuilder
{
    public function withGuid(string $guid): self;
    public function withName(string $name): self;
    public function withTypeId(string $typeId): self;
    public function withCity(string $city): self;
    public function withStreet(string $street): self;
    public function withHouseNumber(string $houseNumber): self;
    public function withPostalCode(string $postalCode): self;
    public function withCountryCode(string $countryCode): self;
    public function withFlatNumber(?string $flatNumber): self;

    public function build(): Address;

    public static function create(
        string $guid,
        string $name,
        string $typeId,
        string $city,
        string $street,
        string $houseNumber,
        string $postalCode,
        string $countryCode
    ): self;
}
```

## Fluent API

- **withGuid(string $guid): self** – ustawia unikalny identyfikator wpisu adresu.  
- **withName(string $name): self** – ustawia czytelną dla człowieka etykietę (np. „Siedziba główna”).  
- **withTypeId(string $typeId): self** – ustawia typ adresu (np. siedziba, korespondencyjny).  
- **withCity/withStreet/withHouseNumber/withPostalCode/withCountryCode(...)** – ustawiają podstawowe komponenty lokalizacji.  
- **withFlatNumber(?string $flatNumber): self** – opcjonalnie ustawia numer lokalu/mieszkania.

- **build(): Address**  
  - Wymaga: `guid`, `name`, `typeId`, `city`, `street`, `houseNumber`, `postalCode`, `countryCode`.  
  - Rzuca `\LogicException`, jeśli któregokolwiek z nich brakuje.  
  - Zwraca nową instancję `Address`.

- **static create(...): self**  
  Wygodna fabryka, która ustawia wszystkie wymagane pola w jednym wywołaniu.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\AddressBuilder;

$address = AddressBuilder::create(
        'addr-guid',
        'Siedziba główna',
        'REGISTERED',
        'Wrocław',
        'Ulica Główna',
        '1A',
        '50-000',
        'PL'
    )
    ->withFlatNumber('2')
    ->build();
```
