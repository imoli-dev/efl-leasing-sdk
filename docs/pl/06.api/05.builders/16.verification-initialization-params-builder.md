## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\VerificationInitializationParamsBuilder` to pomocnik typu fluent do budowania
instancji `VerificationInitializationParams`. Zbiera on dane osobowe i adresowe wymagane do rozpoczęcia
weryfikacji tożsamości za pomocą BlueMedia.

Jest on używany z `/Customer/InitializeIdentityVerification` za pośrednictwem `EflClient::initializeIdentityVerification()`
oraz `CustomerApiClient::initializeIdentityVerification()`.

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `VerificationInitializationParamsBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Verification\VerificationInitializationParams`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Verification\VerificationInitializationParams;

final class VerificationInitializationParamsBuilder
{
    public function withFirstName(string $firstName): self;
    public function withLastName(string $lastName): self;
    public function withResidenceAddressStreet(string $street): self;
    public function withResidenceAddressHouseNumber(string $houseNumber): self;
    public function withResidenceAddressPostalCode(string $postalCode): self;
    public function withResidenceAddressCity(string $city): self;
    public function withEmail(string $email): self;

    public function build(): VerificationInitializationParams;

    public static function create(
        string $firstName,
        string $lastName,
        string $residenceAddressStreet,
        string $residenceAddressHouseNumber,
        string $residenceAddressPostalCode,
        string $residenceAddressCity,
        string $email
    ): self;
}
```

## Fluent API

- **withFirstName/withLastName(string $...): self** – ustawiają imię i nazwisko klienta.  
- **withResidenceAddressStreet/HouseNumber/PostalCode/City(string $...): self** – ustawiają komponenty adresu zamieszkania.  
- **withEmail(string $email): self** – ustawia e-mail używany podczas weryfikacji.

- **build(): VerificationInitializationParams**  
  - Wymaga wszystkich pól: imię, nazwisko, ulica, numer domu, kod pocztowy, miasto, e-mail.  
  - Rzuca `\LogicException`, jeśli któregokolwiek z nich brakuje.  
  - Zwraca nową instancję `VerificationInitializationParams`.

- **static create(...): self**  
  Wygodna fabryka, która ustawia wszystkie wymagane pola w jednym wywołaniu.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\VerificationInitializationParamsBuilder;

$params = VerificationInitializationParamsBuilder::create(
        'Jan',
        'Kowalski',
        'Ulica Główna',
        '1A',
        '50-000',
        'Wrocław',
        'jan.kowalski@example.com'
    )
    ->build();
```
