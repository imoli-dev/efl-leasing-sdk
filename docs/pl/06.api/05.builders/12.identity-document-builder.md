## Przestrzeń nazw i przeznaczenie

`Imoli\EflLeasingSdk\Builder\IdentityDocumentBuilder` to pomocnik typu fluent do budowania instancji `IdentityDocument`.
Reprezentuje on pojedynczy dokument tożsamości (np. dowód osobisty, paszport) powiązany z osobą (`Person`).

## Definicja klasy

- **Przestrzeń nazw**: `Imoli\EflLeasingSdk\Builder`
- **Klasa**: final `IdentityDocumentBuilder`
- **Buduje**: `Imoli\EflLeasingSdk\Model\Customer\IdentityDocument`

```php
namespace Imoli\EflLeasingSdk\Builder;

use Imoli\EflLeasingSdk\Model\Customer\IdentityDocument;

final class IdentityDocumentBuilder
{
    public function withGuid(string $guid): self;
    public function withNumber(string $number): self;
    public function withIssuer(string $issuer): self;
    public function withIssuedOn(string $issuedOn): self;
    public function withTypeId(string $typeId): self;
    public function withValidTo(?string $validTo): self;

    public function build(): IdentityDocument;

    public static function create(
        string $guid,
        string $number,
        string $issuer,
        string $issuedOn,
        string $typeId
    ): self;
}
```

## Fluent API

- **withGuid(string $guid): self** – ustawia GUID dokumentu.  
- **withNumber(string $number): self** – ustawia numer dokumentu.  
- **withIssuer(string $issuer): self** – ustawia organ wydający.  
- **withIssuedOn(string $issuedOn): self** – ustawia datę wydania (ciąg znaków w formacie oczekiwanym przez API).  
- **withTypeId(string $typeId): self** – ustawia identyfikator typu dokumentu.  
- **withValidTo(?string $validTo): self** – opcjonalnie ustawia datę ważności.

- **build(): IdentityDocument**  
  - Wymaga: `guid`, `number`, `issuer`, `issuedOn`, `typeId`.  
  - Rzuca `\LogicException`, jeśli któregokolwiek z nich brakuje.  
  - Zwraca nową instancję `IdentityDocument`.

- **static create(...): self**  
  Wygodna fabryka, która ustawia wszystkie wymagane pola; `validTo` można dodać później za pomocą `withValidTo()`.

## Przykład użycia

```php
use Imoli\EflLeasingSdk\Builder\IdentityDocumentBuilder;

$document = IdentityDocumentBuilder::create(
        'doc-guid',
        'ABC123456',
        'Urząd Miasta',
        '2015-01-01',
        'ID_CARD'
    )
    ->withValidTo('2030-01-01')
    ->build();
```
