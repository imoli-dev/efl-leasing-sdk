## Testy jednostkowe

Uruchom zestaw testów jednostkowych za pomocą:

```bash
composer test
```

To polecenie używa PHPUnit z konfiguracją zdefiniowaną w `phpunit.xml.dist`.

## Pokrycie kodu

Aby wygenerować raport pokrycia kodu, zainstaluj rozszerzenie PCOV lub Xdebug i uruchom:

```bash
composer test:coverage
```

Spowoduje to wyświetlenie tekstowego podsumowania w konsoli oraz wygenerowanie raportu HTML w `build/coverage/`.

Jeśli zobaczysz błędy typu `Unable to load dynamic library 'pcov.so'`, zainstaluj rozszerzenie lub wyłącz je w swoim `php.ini`.

## Testy integracyjne

Testy integracyjne wykonują rzeczywiste połączenia z API sandbox EFL Leasing Online.
Wymagają one zmiennych środowiskowych:

- `EFL_API_KEY`
- `EFL_PARTNER_ID`

Uruchom je za pomocą:

```bash
EFL_API_KEY=your-sandbox-api-key \
EFL_PARTNER_ID=your-partner-id \
composer test:integration
```

Bez tych zmiennych testy integracyjne są pomijane.
