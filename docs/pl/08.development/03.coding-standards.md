---

## Wersja PHP i typowanie

- SDK jest skierowane na **PHP ^8.1** (zalecane 8.2 lub nowsze).
- Wszystkie pliki PHP powinny zaczynać się od:

  ```php
  <?php
  declare(strict_types=1);
  ```

- Używaj ścisłych typów skalarnych i obiektowych dla parametrów oraz wartości zwracanych wszędzie tam, gdzie to możliwe.

## Styl i formatowanie

- Przestrzegaj **PSR-12** w zakresie formatowania i nazewnictwa.
- Używaj dostarczonej konfiguracji PHP-CS-Fixer:

  ```bash
  composer cs-check
  composer cs-fix
  ```

## Analiza statyczna

- Projekt jest skonfigurowany z użyciem **PHPStan**.
- Uruchom analizę za pomocą:

  ```bash
  composer phpstan
  ```

- Nowy kod nie powinien wprowadzać dodatkowych błędów PHPStan ani obniżać poziomu analizy.

## Dokumentacja

- Publiczne klasy, interfejsy i metody powinny być dokumentowane za pomocą PHPDoc, gdy:
  - Typy są złożone lub nieoczywiste.
  - Zachowanie lub niezmienniki są nietrywialne.
  - Istnieją ważne przypadki brzegowe lub ograniczenia domenowe.
- Komentarze powinny wyjaśniać **dlaczego** kod został napisany w określony sposób, a nie powtarzać to, co robi.
