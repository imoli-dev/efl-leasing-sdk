## Uzyskanie poświadczeń sandbox

Aby korzystać z sandboxa, potrzebujesz:

- Klucza API.
- Identyfikatora partnera (`partnerId`).

Oba są dostarczane przez EFL. Zapoznaj się z oficjalną dokumentacją sandboxa, aby dowiedzieć się, jak je uzyskać.

## Konfiguracja SDK dla sandboxa

```php
use GuzzleHttp\Client as GuzzleClient;
use Imoli\EflLeasingSdk\Config;
use Imoli\EflLeasingSdk\EflClient;
use Imoli\EflLeasingSdk\Http\Adapter\GuzzleHttpAdapter;

$config = Config::sandbox(
    apiKey: 'your-sandbox-api-key',
    baseUrl: 'https://leasingonlineapi-sandbox.efl.com.pl'
);

$guzzle = new GuzzleClient([
    'timeout' => 30,
    'connect_timeout' => 10,
]);

$httpClient = new GuzzleHttpAdapter($guzzle);

$client = new EflClient($config, $httpClient);
```

## Zmienne środowiskowe

W wielu projektach wygodnie jest przechowywać poświadczenia w zmiennych środowiskowych, na przykład:

- `EFL_API_KEY`
- `EFL_PARTNER_ID`

Następnie możesz zbudować konfigurację w ten sposób:

```php
$config = Config::sandbox(
    apiKey: getenv('EFL_API_KEY'),
    baseUrl: 'https://leasingonlineapi-sandbox.efl.com.pl'
);

$partnerId = getenv('EFL_PARTNER_ID');
```

## Uruchamianie testów integracyjnych

Repozytorium SDK zawiera testy integracyjne, które wykonują rzeczywiste połączenia z API sandbox.
Są one uruchamiane za pomocą:

```bash
EFL_API_KEY=your-sandbox-api-key \
EFL_PARTNER_ID=your-partner-id \
composer test:integration
```

Używaj tych testów jako punktu odniesienia dla rzeczywistych przepływów żądań/odpowiedzi oraz rozwiązywania problemów.
