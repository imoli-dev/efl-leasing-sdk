## Wzorzec 1: Metoda płatności w procesie zamówienia

W tym wzorcu EFL Leasing jest jedną z metod płatności oferowanych podczas składania zamówienia (checkout).

Wysokopoziomowy przepływ:

1. Klient wybiera EFL Leasing podczas zamówienia.
2. Backend inicjuje konfigurację i [`EflClient`](../06.api/02.efl-client/01.overview.md).
3. Backend pobiera token autoryzacyjny i rozpoczyna proces.
4. Backend oblicza oferty na podstawie koszyka.
5. Frontend wyświetla dostępne oferty i przekierowuje klienta do przepływu EFL, gdy jest on gotowy.

Kluczowe metody SDK:

- `getAuthToken()`
- `startProcess()`
- `calculateBasicOffer()`
- Metody przesyłania danych klienta i weryfikacji, gdy klient kontynuuje proces.

## Wzorzec 2: Odpytywanie o status w tle

W tym wzorcu Twój backend okresowo odpytuje API EFL w celu zaktualizowania statusu procesów leasingowych.

Typowe kroki:

1. Zapisanie identyfikatorów procesu podczas jego rozpoczynania.
2. Zaplanowanie zadań w tle do odpytywania o stan procesu.
3. Użycie niskopoziomowych klientów API lub dedykowanych metod [`EflClient`](../06.api/02.efl-client/01.overview.md) do pobrania statusu.
4. Aktualizacja własnych rekordów zamówień lub umów na podstawie wyników.

Ten wzorzec oddziela przepływy widoczne dla użytkownika od czasu zewnętrznych aktualizacji.

## Wzorzec 3: Pozyskiwanie leadów

Możesz użyć SDK do wysyłania leadów i formularzy kontaktowych do systemów EFL nawet poza pełnym procesem leasingowym.

Typowe kroki:

1. Zebranie podstawowych danych kontaktowych i zainteresowań z formularza.
2. Zbudowanie modelu `ContactData`.
3. Wywołanie `EflClient::sendContactForm()` w celu zarejestrowania leada.
4. Przechowywanie referencji zwróconych przez API do późniejszego śledzenia.

Ten wzorzec jest przydatny, gdy chcesz uchwycić zainteresowanie przed pełnym procesem zakupu.

## Łączenie wzorców

Większość rzeczywistych integracji łączy te wzorce:

- Metoda płatności w procesie zamówienia z odpytywaniem w tle.
- Punkty wejścia dla pozyskiwania leadów, które później przechodzą w pełne procesy leasingowe.

SDK zostało zaprojektowane do użycia w Twoich własnych usługach aplikacyjnych, dzięki czemu możesz komponować te wzorce zgodnie z potrzebami Twojej domeny.
