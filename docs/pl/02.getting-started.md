## Wymagania wstępne

Zanim zaczniesz, upewnij się, że posiadasz:

- PHP >= 8.1 (zalecane 8.2 lub nowsze) z włączonym rozszerzeniem `ext-json`.
- Composer do zarządzania zależnościami.
- Dostęp do sandboxa EFL Leasing Online (klucz API i partner ID).

Będziesz także potrzebować implementacji klienta HTTP. SDK zawiera adaptery dla:

- Guzzle (`GuzzleHttp\Client`)
- Symfony HttpClient (`Symfony\Component\HttpClient\HttpClient`)

Możesz również dostarczyć własną implementację [`HttpClientInterface`](06.api/07.http.md#httpclientinterface).

## 1. Zainstaluj SDK

Zainstaluj SDK w swoim projekcie zgodnie z opisem w przewodniku [Instalacja](03.installation.md).
Po zainstalowaniu SDK jest dostępne w przestrzeni nazw `Imoli\EflLeasingSdk`.

## 2. Utwórz konfigurację

Użyj obiektu wartości [`Config`](05.configuration.md), aby opisać środowisko i uwierzytelnianie.
Dla środowiska sandbox:

```php
use Imoli\EflLeasingSdk\Config;

$config = Config::sandbox(
    apiKey: 'your-sandbox-api-key',
    baseUrl: 'https://leasingonlineapi-sandbox.efl.com.pl'
);
```

Dla produkcji użyjesz `Config::production()` z innym bazowym adresem URL i kluczem API, jak opisano w sekcji **Konfiguracja**.

## 3. Skonfiguruj klienta HTTP

Musisz dostarczyć implementację [`HttpClientInterface`](06.api/07.http.md#httpclientinterface). Zalecanym sposobem jest użycie jednego z adapterów:

```php
use GuzzleHttp\Client as GuzzleClient;
use Imoli\EflLeasingSdk\Http\Adapter\GuzzleHttpAdapter;

$guzzle = new GuzzleClient([
    'timeout' => 30,
    'connect_timeout' => 10,
]);

$httpClient = new GuzzleHttpAdapter($guzzle);
```

lub z Symfony HttpClient:

```php
use Imoli\EflLeasingSdk\Http\Adapter\SymfonyHttpAdapter;
use Symfony\Component\HttpClient\HttpClient;

$symfonyClient = HttpClient::create();
$httpClient = new SymfonyHttpAdapter($symfonyClient);
```

Możesz także samodzielnie zaimplementować [`HttpClientInterface`](06.api/07.http.md#httpclientinterface), jeśli chcesz zintegrować się z innym stosem HTTP.

## 4. Utwórz głównego klienta

Zainicjuj [`EflClient`](06.api/02.efl-client/01.overview.md) z konfiguracją i klientem HTTP:

```php
use Imoli\EflLeasingSdk\EflClient;

$client = new EflClient($config, $httpClient);
```

Ten klient udostępnia wysokopoziomowe metody dla typowych przepływów ecommerce, takich jak:

- Uwierzytelnianie i inicjalizacja procesu.
- Kalkulacja oferty.
- Przesyłanie danych klienta i oświadczeń.
- Weryfikacja tożsamości i pay‑by‑link.

## 5. Wykonaj pierwsze wywołanie

Jako pierwszy krok zazwyczaj pobierasz token uwierzytelniający i inicjujesz proces.
Dokładne metody mogą ewoluować wraz z SDK, ale ogólny wzorzec to:

```php
// Pseudokod – sprawdź sekcję API pod kątem dokładnych nazw metod i sygnatur.

// Token Bearer zwrócony przez getAuthToken(), używany w kolejnych wywołaniach
$token = $client->getAuthToken($partnerId);

$process = $client->startProcess(
    positiveReturnUrl: 'https://example.com/efl/success',
    negativeReturnUrl: 'https://example.com/efl/failure',
    token: $token
);
```

Następnie możesz obliczać oferty, przesyłać dane klienta i przeprowadzać procesy weryfikacji.
Zobacz sekcje **Szybki start** i **Przewodniki**, aby zapoznać się z pełnymi przykładami.
